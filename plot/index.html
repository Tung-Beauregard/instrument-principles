數據畫圖

把儀器匯出的檔案放進來,就畫成報告用的圖:黑白、完整框線、座標黑字。可以下載 SVG(插進 PowerPoint 後按右鍵「轉換成圖案」就能逐條編輯)或 300 dpi 的 PNG。檔案只在你的瀏覽器裡處理,不會上傳。

把檔案拖到這裡,或點一下選檔 可以一次放好幾個;同一種數據會疊在同一張圖

認得的檔案:FTIR 的 .spc、.asp;PerkinElmer 匯出的 DSC 或 TGA .csv(要有 Program Temperature 欄);溫度欄配重量欄的 TGA .xlsx;Thermo LCQ Deca XP 的 .RAW;兩欄數字的 .txt 或 .csv。

檔案

放進檔案後,圖會出現在這裡。

光譜以原檔的吸光度畫,曲線只加固定位移;質譜把選定掃描的峰疊在一起,每 0.1 取 ±0.65 的視窗加總再除以掃描張數,局部最大值畫成一根棒;DSC 依程式溫度分升溫與降溫段;TGA 以第一點為 100%,DTG 用 1 °C 格點做移動平均。做法細節見 plot/MAINTENANCE.md。
