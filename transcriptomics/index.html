轉錄體分析 從定序資料找出候選基因

RNA-seq 讀出幾千萬條短序列之後,要先清理品質、對回基因體或從頭組裝,再計數、標準化,用統計找出處理後真的改變的基因,最後結合序列註解與萜類含量,挑出值得選殖的萜類合成酶候選。

自己調整

章節

    重點整理

    先看:DNA 定序(RNA-seq 入門)、萜類合成酶(找出基因、做出酵素)

    • FASTQ 每條 read 四行:名稱、序列、+、品質。品質字元的 ASCII 碼減 33 是 Phred 分數,Q = −10·log₁₀(p):Q20 表示判讀錯的機率 1%,Q30 是 0.1%。越往 3′ 端品質越差;片段比讀長短時會讀進接頭,要先切掉接頭再修剪低品質的尾巴。
    • 有參考基因體就把 read 對回去,跨過外顯子接點的 read 要拆成兩段、跳過內含子(STAR、HISAT2);沒有參考基因體(很多針葉樹)就從頭組裝:Trinity 把 read 切成 k-mer 接成 de Bruijn 圖。圖上的分岔有兩種來源:同一個基因的不同剪接方式(異構體),或是 k 太小時,重複的小段被黏成同一個節點。
    • RPKM = 計數 ÷(長度 kb × 總讀數 百萬);TPM 先除以長度,再換成占全部的比例乘一百萬,所以每個樣品的 TPM 加總都是一百萬。兩者都是樣品內的相對量,比較樣品之間要用 DESeq2 的 size factor(median of ratios),它不受少數大量增加的基因影響。
    • 計數的變異比平均數大,負二項分布寫成 Var = μ + αμ²,也就是 CV² = 1/μ + α:讀數多時剩下個體之間的差異 α,再加深定序幫助不大,要增加生物重複(至少 3 個,6 個以上更穩)。
    • 同時檢定幾千到幾萬個基因要做多重檢定校正:Benjamini–Hochberg 把 p 值排序,找最後一個 p₍ᵢ₎ ≤ (i/m)·q 的名次,它和前面的全部算顯著,控制偽發現率(FDR)。火山圖的橫軸是 log₂FC、縱軸是 −log₁₀(校正後 p)。
    • 挑萜類合成酶候選:BLAST 的 E 值要小、要有 Pfam 的 N 端結構域(PF01397)與金屬結合結構域(PF03936)和 DDxxD、讀框要完整,再看處理後是否上升、和萜類含量是否一起變。序列像不代表知道產物:接著要選殖、在大腸桿菌表現、加 GPP 反應確認產物,並用 qPCR 確認表現量。
