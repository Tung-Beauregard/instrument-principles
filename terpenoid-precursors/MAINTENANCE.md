# 萜類前驅物(`terpenoid-precursors/`)維護說明

生化進階分區的一份教材(2026-10-27)。接在「萜類合成酶」(`terpene-synthase/`)之後:那一份的第 2 章講 IPP 與 DMAPP 怎麼頭尾相接成 GPP、FPP、GGPP,這一份講這兩塊 5 碳積木從哪裡來(質體的 MEP 路徑、細胞質的 MVA 路徑)、各花多少碳與能量、接長鏈時兩種積木要怎麼配、怎麼用抑制劑與同位素標記判斷萜類的碳從哪條路來,最後是骨架之後 P450 怎麼把雙萜氧化成針葉樹的樹脂酸。播放器、版面與畫圖工具和其他生化教材共用,約定見 `pcr/MAINTENANCE.md` 的「播放器的約定」。

## 共用的小工具(module 前段)

- `fin(t, a, d)`:從 a 秒開始、d 秒內由 0 漸變到 1(`ease(seg())` 的縮寫)。`alpha(g, a, fn)`:在透明度 a 底下畫 fn。
- `rich(g, x, y, parts, o)`:一行有上標的字(`parts` 是 `[文字, 是否上標]`),第 6 章的公式用它,不靠 Unicode 的 ᵏ 這類字型不一定有的字元。
- `steps(g, x, y, list, t)`:右邊的步驟清單,`list` 是 `[標題, 說明, 開始秒數]`,目前這一步框起來。`count()`:小標題加大數字(第 2、3、4 章的帳)。
- `along(pts, f)`、`flow(g, pts, t, o)`:沿著折線流動的小點;`stop` 以後的點不畫(被抑制劑擋住)。`arrowLine()`:折線箭頭。`node()`:流程圖的圓角節點(有不透明底色,所以要先畫流動的點、後畫節點,點才不會蓋到字)。
- `choose(n, k)`、`binom(n, p)`:二項分布;`pct(v, d)`:百分比字串。
- `drawMol(g, A, B, k, o)`:分子的畫法,見下一節。`morphAt(t, first, seq)`:依時間決定目前畫哪兩個狀態與內插比例,`seq` 是 `[開始, 結束, 狀態 A, 狀態 B]`,回傳 `[A, B, k, 第幾段]`。`XZ(k)`(鋸齒鏈第 k 個碳的 x)、`rot(c, 角度, r)`、`mv(p, d, k)`:座標小工具。

## 分子的畫法(`drawMol`)

- 分子是 `{ P: { 代號: [x, y] }, T: { 代號: '文字' }, B: [[i, j, 鍵級, 環中心(選用)]] }`,座標以鍵長為 1、y 朝下。`T` 裡有字的原子是官能基(畫字,字後面有一圈底色,鍵在字的外框截斷);沒有字的是碳(畫圓點,顏色由 `o.col[代號]` 決定,用來看碳從哪裡來)。`o.dots === false` 時只畫線(第 7 章的骨架式),`o.only` 裡的碳仍畫點。
- 給了狀態 B 時在兩個狀態之間內插:位置照 k 內插(`o.over[代號]` 可以直接指定,用來畫轉動、飛走、從上方繞過去);只在 A 的原子在前 60% 淡出、只在 B 的在後 60% 淡入;斷掉的鍵在前 35% 消失、新的鍵在最後 35% 才出現(原子還在半路時不會拉出長線);鍵級改變(單鍵與雙鍵互換)照 k 漸變;官能基的字在 k = 0.5 前後換(各 0.08),不會疊成亂碼。`o.alphaOf(代號)` 可以再乘一個透明度。
- 雙鍵沒有給環中心時兩條線置中;給了環中心(第 7 章)時主線在原位,第二條線往環的中心內縮。`o.ring` 是要加圈的碳(第 3 章的 ¹³C),`o.num` 在碳旁寫編號。

### 第 2 章的分子(`MV`、`MV_SEQ`、`mvOver`)

- 碳的代號:a、b、c 是三個乙醯基,1 是羰基碳、2 是甲基碳,顏色 `MV_COL`(琥珀、薄荷綠、藍)。`dB`、`dC` 是第二、三個乙醯輔酶 A 等待的位置(相對於反應後的位置平移,進場時是純平移,不會交叉)。
- 狀態:`m0` 三個乙醯輔酶 A、`m1` 乙醯乙醯輔酶 A、`m2` HMG-CoA、`m3` 甲羥戊酸、`m3b` 甲羥戊酸-5-磷酸、`m4` 甲羥戊酸-5-二磷酸、`m5` IPP、`m6` DMAPP。
- 碳的對應(用來核對):IPP 的 1 號碳 = a1、2 = a2、3 = b1、4 = c2、5 = b2;脫羧放掉的 CO₂ 是 c1(第三個乙醯基的羰基碳,也就是 HMG-CoA 的游離羧基)。這和「[2-¹³C] 乙酸標在 IPP 的 2、4、5 號碳」一致。
- `mvOver`:第 0 段第二個乙醯基的輔酶 A 往下飄走;第 1 段 b2(甲基)繞 b1 從左上轉到左下,讓第三個乙醯基接上來;第 2 段輔酶 A 離開、羰基的氧繞 a1 轉到右上變 -OH;第 5 段羧基(c1 與兩個氧)往左下飛走、3 號碳的 -OH 往右下離開。離開的輔酶 A 另外用 `alphaOf` 提早淡出。

### 第 3 章的分子(`ME`、`ME_SEQ`、`meOver`)

- p1 到 p3 是丙酮酸的 1 到 3 號碳(p1 是羧基),g1 到 g3 是 G3P 的 1 到 3 號碳(g1 是醛基);顏色 `ME_COL`(丙酮酸琥珀、G3P 藍)。
- DXR 重排:G3P 的 2、3 號碳那一段(連同 -OH 與磷酸)從 g1 搬到 p2 上。這一段在 DXP 裡叫 `d2、dO2、d3、dP`,在 MEP 之後叫 `g2、Og2、g3、Pg`(`FRAG` 是對照表);`meOver` 讓前一組沿弧線走前 60%、後一組走後 60%,`alphaOf` 讓兩組在半路交接。直接內插會讓四個原子在半路擠成一團(兩邊的方向是鏡像),所以用交接。重排分三段:`n1 → n1b` 斷鍵、`n1b → n2b` 搬過去、`n2b → n2` 接上新鍵。
- 狀態:`n0` 丙酮酸 + G3P、`n1` DXP、`n2` MEP、`n3a` CDP-ME(磷酸那端寫 O-CDP)、`n3b` CDP-MEP(2 號碳的 -OH 變 OP)、`n3c` MEcPP(`ring: true`,上方畫一條弧表示環狀二磷酸)、`n4` HMBPP、`n5` IPP。
- 碳的對應:IPP 的 1 號碳 = g3、2 = g2、3 = p2、4 = g1、5 = p3。從 [1-¹³C] 葡萄糖來的標記在 G3P 的 3 號碳與丙酮酸的 3 號碳,所以 MEP 做的 IPP 在 1、5 號碳帶 ¹³C。
- **化學上要對的地方**:HMBPP 是 E 型,4 號碳(g1,接 -OH)和 1 號碳(g3,接二磷酸)在雙鍵(p2 = g2)的兩側,所以 MEP 之後 g2 接在 p2 的左上、g3 往左;改座標後用叉積核對兩側。IPP 的雙鍵在 p2 = g1(3、4 號碳),DMAPP 在 p2 = g2。
- 第 3 章最後的 `IPPS`(兩條路共用的 IPP 圖)與 `IPPS_NUM`(編號位置);MVA 圈 2、4、5 號碳,MEP 圈 1、5 號碳。

### 第 7 章的分子(`AB`、`OX`、`abState`)

- 松香烷(abietane)骨架:三個六員環排成菲的樣子,環 A 在左下、B 在中間、C 在右上,編號照 abietane:C10 上的 20 號甲基朝上、C4 上的 19 號甲基朝右下、18 號碳(`G18`)朝左下、C13 上接異丙基。abietadiene 與松香酸的雙鍵在 C7 = C8(環 B)與 C13 = C14(環 C),第二條線往環中心內縮(`RB`、`RC`)。改座標後用 node 檢查每個碳的鍵級總和不超過 4(見「修改後要檢查」)。
- `G18` 的字依氧化步驟換:CH₃(abietadiene,烯)、CH₂OH(abietadienol,醇)、CHO(abietadienal,醛)、COOH(abietic acid,松香酸)。

## 計算模型與公式

1. **碳與輔因子的帳**(第 2、3、8 章,`budget(route, n)`):照 KEGG 的反應式(模組 M00095、M00096 的各步反應)。
   - MVA,每個 IPP:3 乙醯輔酶 A + 2 NADPH + 3 ATP → IPP + CO₂(另放出 3 個輔酶 A、3 個 ADP、1 個磷酸)。
   - MEP,每個 IPP 或 DMAPP:丙酮酸 + G3P + NADPH + CTP + ATP + 4 個還原態鐵氧化還原蛋白 → IPP 或 DMAPP + CO₂(DXS 放 CO₂、DXR 用 NADPH、IspD 用 CTP、IspE 用 ATP、HDS 與 HDR 各用 2 個還原態鐵氧化還原蛋白)。
   - 第 8 章從三碳化合物算起:MEP 進 6n 個碳(丙酮酸 n + G3P n)、放 n 個 CO₂;MVA 進 9n 個碳(3n 個丙酮酸)、放 4n 個 CO₂(3n 個在丙酮酸變成乙醯輔酶 A 時,n 個在脫羧)。留下的比例 5n ÷ 進來的碳 = MEP 5/6(83.3%)、MVA 5/9(55.6%),和鏈長無關。輔因子:MEP 的 ATP、CTP、NADPH 各 n,還原態鐵氧化還原蛋白 4n;MVA 的 ATP 3n、NADPH 2n。只算用掉的,不算 PDH 產生的 NADH、輔因子再生、運輸與光合作用本身。
   - 把做 ATP、NADPH 用掉的糖也算進去時,Zhao et al. 2013 給的理論質量產率是 MEP 30%、MVA 25%(頁面直接引用,沒有自己算)。
2. **IDI 要轉多少**(第 4 章,`idiNeed(n, d0)`):5n 個碳的鏈要 1 個 DMAPP 加 n − 1 個 IPP,需要的 DMAPP 比例是 1/n;原料裡已有的 DMAPP 比例 d₀(`D0`:質體 0.15,取自 HDR 在菸草 BY-2 細胞的 85:15;細胞質 0,MVA 只做 IPP),IDI 要把 1/n − d₀ 的原料從 IPP 轉成 DMAPP。60 格:GPP 30 − 9 = 21 格(35%)、FPP 20 − 0 = 20 格(33.3%)、GGPP 15 − 9 = 6 格(10%)。這是只算單一產物的帳(示意);實際的原料池同時供應很多產物,IDI 的量由整體需求與調控決定。
3. **同位素的二項分布**(第 6 章):每個 5 碳單位帶標記(多 2 個氘)的機率 p,n 個單位(單萜 2、倍半萜 3)中剛好 k 個帶標記的比例 C(n,k)·p^k·(1 − p)^(n−k),質量 +2k;被標記的比例 1 − (1 − p)^n,和 Dudareva 2005 定義的「percent labeling」(位移的離子 ÷(位移 + 未位移))相同。虛線是「質體只送出 GPP、細胞質的 IPP 沒有標記」的預測:倍半萜 = GPP 的 n = 2 分布再接 1 個未標記單位,所以 +6 為 0。MVL:單萜全部 +0(論文測不到標記),倍半萜用 n = 3。論文沒有用這個模型,p 是可調的示意值;長條沒有計入天然同位素(¹³C 的 +1、+2)與氘的同位素效應。
4. **第 5 章的曲線**:`monoFos(h)` 在 3 小時剛好是 40(少 60%,取自論文),之後緩降到 12 小時約 33(示意);`sesqFos(h)` 3 小時約 74、12 小時 48(示意,論文只說比單萜慢);`sesqLova(h)` 在 100 上下 1.5(論文:幾乎沒有影響);`expSesqLova(h)` 是照課本分工的預期(示意)。lovastatin 下的單萜論文沒有給數據,畫面寫「單萜:論文沒有給數據」,不畫實線。

用 node 驗算過(把 module 的純函式抽出來執行):p = 0.3 時單萜 0.49、0.42、0.09(被標記 51%),倍半萜 0.343、0.441、0.189、0.027(65.7%);p = 0.8 時倍半萜 0.008、0.096、0.384、0.512;IDI 35%、33.3%、10%(21、20、6 格);碳帳 MEP n = 2 進 12、CO₂ 2、留 83.3%,MVA n = 4 進 36、CO₂ 16、留 55.6%;`monoFos(3)` = 40;MVA 各狀態 6、6、6、6、6、5、5 個碳,MEP 6、5、5、5、5 個碳,松香烷 20 個碳、每個碳的鍵級總和不超過 4。
