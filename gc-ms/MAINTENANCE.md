# GC-MS 教材維護

本文件涵蓋 2026-10-05 的效能變更與 2026-10-07 的鏡頭、放大鏡、點選放大與動畫說明；完整模型座標、科學公式、鏡頭與導覽時間軸仍待補齊。科學資料見 `../INSTRUMENTS.md`。

- `index.html` 內嵌 module；`initUI()` 與 `init3D()` 初始化介面與 Three.js，`G.ready` 表示模型可繪製。3D 載入失敗仍保留圖表與控制。
- `frame()` → `step()` → `tick()` / `update3D()` / `G.composer.render()`；背景分頁略過，前景最高 60 FPS。
- `tick()` 中圖表由 `chartClock` 限制最高每秒 30 次；時間、成分、質譜、粒子和鏡頭的原本計算不改。`drawChrom/drawOver/drawMS/drawOven` 保留原資料與公式。
- `resize3D()` 同步 renderer 與 composer 的繪圖比例，再更新粒子尺寸。`quality.configure()` 設定陰影、MSAA 與 bloom，完整模式保留原後製。
- 畫質選單在 `.ctl`；手機和平板用原有「設定」開啟控制面板。選單等 renderer 初始化後才啟用。
- 拆解由 `S.explode` / `S.explodeTarget` 與 `update3D()` 管理；不要因效能調整改寫 `rebuildColumn` 管柱位置。導覽由 `tourTick/tourCamera` 管理。
- 視角操作（2026-10-07）：`init3D()` 建立 `G.nav`（共用的 `../assets/camera-nav.js`），`update3D()` 在非導覽分支、`G.fly` 之後呼叫 `G.nav.step(dt)`。滑鼠滾輪縮放，觸控板雙指平移、捏合縮放，方向鍵或 WASD 移動、+/− 縮放。Q（質譜面板）與 R（`resetView()`）維持本頁原有功能，所以不開 Q/E 轉向、不接管 R。使用者一操作就和拖曳一樣接手鏡頭：清掉 `G.fly`、`G.injCam`，設 `G.userMoved`，導覽中則經 `userTakesOver()` 結束導覽。說明視窗開著時不作用。觀察點限制在 `DEF_VIEW.tgt` 半徑 380 的球內。
- 世界左右鏡像：`G.world.scale.x = -1`，所以世界座標的 +x 是遠離質譜顯示幕的方向。`tourCamera()` 偵測器一站的鏡頭偏移是 `V3(10, 14, 52)`，從正面窗口斜看進去；以前是 `V3(-12, 12, 34)`，鏡頭落在顯示幕那一側又貼得太近，畫面被外殼擋住。改任何取景前先確認鏡像方向。
- 正面外殼自動淡出（2026-10-07）：`update3D()` 把鏡頭位置換到 `G.msd` 的本地座標，鏡頭在質譜正前方、離正面 18 單位內時，正面外殼（`M.shellFade`）、窗玻璃（`G.msWin` 的 `uFade`）和小螢幕（`G.msScr`）一起淡出，貼近正面 4 單位內完全透明。和拆開共用同一個淡出值 `G.frontFade`（取兩者較大的），淡出過半就不寫深度。
- 空腔不可以和外殼共面：柱溫箱的 `M.cavity` 與質譜內腔的 `M.cavityDark` 都是只畫背面的盒子，四壁比外殼內側內縮 0.15。以前完全貼齊，兩個面搶著顯示，從窗口斜看會出現閃爍的條紋（導覽第 5 到 8 站最明顯）。之後加任何貼著外殼的內襯或面板，也要留這個間隙。
- 放大鏡預設收起（2026-10-07）：`update3D()` 先算 `lensWant`（這時放大鏡派得上用場：沒有導覽時是鏡頭夠遠，導覽時是第 3、4、5 站），真正顯示要再看 `S.lensOpen`（使用者按角落的按鈕打開，只在這次開頁有效）或導覽中的 `G.lensTourOff`（按 × 只收起這一站，`onTourChange()` 時清掉）。`placeLensBtn()` 管那顆按鈕：收起時放在放大鏡會出現的角落並寫「放大鏡:離子源」或「放大鏡:管柱內部」，打開時變成放大鏡右上角的 ×。按鈕寬高只在文字換掉時量一次（`b._w`、`b._h`），不要每格量。說明框裡「暫停在這支峰上」那句依 `S.lensOpen` 換說法。
- 放大鏡位置（`placeLens()`，2026-10-07）：自動模式依版面列出角落，蓋到觀察點（`controls.target` 的投影，周圍留 70 px）就換下一個角落。導覽中四個角落都會蓋到時（手機的可視區只有約 360×180），放大鏡留在第一個角落，由 `lensDodge()` 算出觀察點往左右或上下哪一邊移最少，`G.viewShift` 慢慢跟上，`updateViewOffset()` 把這段平移加進投影中心；鏡頭和觀察點本身不動。判斷是否蓋到時要先扣掉目前的平移，不然平移完又判定沒蓋到，會來回跳。非導覽時找不到角落就把放大鏡縮成 0.7 倍。放大鏡是跟著鏡頭的 3D 物件，深度 `G.lensC.D` 取鏡頭到觀察點距離的 0.35 倍（6 到 90），鏡頭靠近儀器時放大鏡也跟著靠近，不會插進儀器裡。
- 拖放大鏡、點部件放大（`initPointerTools()`，2026-10-07）：畫布上的捕獲階段 `pointerdown` 若落在 `G.lensRect` 裡就改成拖放大鏡，用 `stopImmediatePropagation()` 擋掉 OrbitControls，視角不會跟著轉；拖到的位置記成可視區裡的比例 `G.lensUser`，雙擊放大鏡清掉、回到自動位置。沒拖動的單擊（450 ms、6 px 內）交給 `zoomAt()`：射線只打 `G.world`，略過隱藏的物件、玻璃和淡出的外殼；落點 28 單位內有部件標籤就用那個標籤的取景（`buildTags()` 裡的 `ZOOM`，存成 `G.ZOOM`），打到外殼或從窗口打到內牆就放大整台（質譜儀、管柱烘箱、ALS 自動進樣器），其餘沿目前的方向拉近。有取景的標籤加 `.zoomable`，本身也能點。`zoomTo()` 和使用者自己操作一樣接手鏡頭（`userTakesOver()`、清掉 `G.injCam`、設 `G.userMoved`）。
- 畫面文字（2026-10-07）：說明、標籤、讀值改成高中畢業看得懂的白話，原則見 `../AGENTS.md` 第 5 節；型號只留在頁尾小字與說明。
- 動畫說明（2026-10-07）：`XP` 的四段（`part` 走走停停、`ki` 保留指數、`ei` 電子撞擊游離、`quad` 四極桿）各有 `title`、`dur`、`cues`（[開始秒數, 說明]）與 `draw(c, t)`，畫在 600 × 340 的虛擬座標。前三段是時間的純函式：走走停停預先算好 120 顆分子進出液膜的時間（每次停留取平均值上下 30%，畫面只畫前 16 顆），層析圖用全部 120 顆抵達偵測器的時間疊成；保留指數每次畫都從 `getRun(3)`、`getRun(10)` 拿本頁模型的烷類與 α-Pinene 時間，所以改了滯留模型這裡會跟著變；電子撞擊游離用 `FRAG.apin` 的斷法與 `CPDS` 裡 α-Pinene 的主要離子。四極桿那段用共用的 `assets/analyzer-fields.js`（見 `../mass-analyzers/MAINTENANCE.md` 與 `INSTRUMENTS.md`），`seek()` 往回跳時會從頭重算。控制：`openXP(k, opener)`、`closeXP()`、`setXPTopic()`、`xpSeek()`、`xpJump()`、`xpToggle()`；開著時 `frame()` 直接跳過（3D 不畫），播放與導覽暫停，關閉後恢復並把焦點還給打開它的按鈕；鍵盤 Esc、空白鍵、左右鍵在 keydown 最前面處理。入口：控制列的「動畫」（`btnXp`，開上次看的那段）、說明視窗的 `.xp-open` 按鈕、四極桿面板的「電場動畫」（`btnQuadXp`）、牆上的說明圖。
- 牆上的說明圖：`POSTER_X` 與 `POSTER_Y` 決定四張的位置（放低到中心高 80，預設視角比較不會被上方面板切掉；仍有幾張在面板後面，所以另外有「動畫」按鈕）。`drawPosters()` 畫內容與右上角「點一下看動畫」，第四張「四極桿」用 `createFieldDemo(...).draw(g, { bare: true })` 畫在海報上。點擊在 `zoomAt()`：射線先打說明圖（`G.posterMeshes`），比儀器近才打開動畫；滑過時 `posterAt()` 把游標換成手指。
- 除錯：`window.GCMS = { G, S, TAGS, xp: { open, seek } }` 給自動測試讀鏡頭、放大鏡與標籤狀態、跳到動畫的某一秒，不要拿來寫功能。
- 檢查：進樣、播放/暫停、拆開/組裝、設定與鍵盤、各畫質、TIC 與 MS 圖、390/768/桌面；視角操作與 Q、R 等原有快捷鍵；點部件與標籤放大、放大鏡的開關、拖放大鏡與雙擊歸位；導覽第 5、7、8 站沒有條紋，手機寬度第 5 站的離子源露在放大鏡旁邊；四段動畫與各個入口、Esc 的順序。細節見 `../docs/VALIDATION.md`。
