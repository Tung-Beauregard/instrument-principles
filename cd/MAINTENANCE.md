# CD 圓二色光譜儀:維護說明

`cd/index.html` 是單一 HTML 檔,用 three.js 0.183.2(jsDelivr 的 ES module,經 importmap 載入)繪圖,元件標籤用 three.js 的 `CSS2DRenderer`,不需要建置。畫面是一台拆開的圓二色光譜儀:氙燈、晶體石英雙稜鏡單色器(兼作起偏)、光彈調變器(PEM)、樣品、可滑進光路的檢偏鏡、光電倍增管與鎖相放大器,另有氮氣流量計。同一台上可以切換「圓二色」與「旋光」兩種量法;沿光路把光的振動方向畫出來(線偏振是一片平面的波加雙箭頭,圓偏振是螺旋)。「導覽」與影片共用同一條 99.6 秒、8 章的腳本(`?film`、`?rec`)。科學資料與來源見 `../INSTRUMENTS.md`,檢查步驟見 `../docs/VALIDATION.md`。

**正本:** 儲存庫裡的 `cd/index.html` 就是正本(2026-11-19 新增),直接改這個檔。版面與骨架從 `uv-vis/index.html` 複製後改寫(導覽、影片、手機版面、畫面大小、英文版的做法都相同,見 `../uv-vis/MAINTENANCE.md`);module 的大區以 `// ================= 名稱 =================`、小區以 `// ---------- 名稱 ----------` 標示。

**對應的儀器:** 頁面不寫型號;元件的種類以常見的桌上型圓二色光譜儀為例,規格參考 JASCO J-1500 與 Applied Photophysics Chirascan(型號只寫在說明框小字)。旋光以一般旋光儀(鈉 D 線 589 nm、1 dm 樣品管)為例,和 CD 放在同一台上方便比較。實機的線偏振由單色器的晶體石英稜鏡直接產生,所以模型裡沒有另一片偏振片。

## 光譜模型

### 圓二色(`CD`)

每個樣品的 `bands` 是 `[中心 nm, 寬度 σ nm, 這個條件下的橢圓度 mdeg]`,高斯相加(`thetaAt()`,單位 mdeg)。寬度全是示意(筆記沒有峰寬的數據)。

| 鍵 | 按鈕 | 條件 | 吸收帶 | 狀態 |
|---|---|---|---|---|
| `csaP` | (+)-樟腦磺酸 | 0.06% 樟腦磺酸銨、1 cm | `[290.5, 17, 190]`、`[192.5, 9.5, -390]` | 峰位與高度由文獻 Δε 算出;寬度示意 |
| `csaM` | (−)-樟腦磺酸 | 同上 | 正負相反 | 由鏡像對稱推得 |
| `helix` | α 螺旋 | 肌紅蛋白 0.1 mg/mL、1 mm | `[223, 6.8, -20.807]`、`[207, 5.0, -19.526]`、`[191.5, 6.0, 42.364]` | 三個振幅是解聯立方程讓 222 nm = −20.8(文獻算出)、208 nm ≈ −20、192 nm ≈ +42(後兩個示意);算出來的曲線極小在 208.4 與 222.8 nm、極大在 191.4 nm、零點 201.5 nm |
| `sheet` | β 褶板 | 示意的蛋白質 0.1 mg/mL、1 mm | `[217, 8.5, -7.594]`、`[196, 6.5, 17.359]` | 整條示意(218 nm 約 −7.5、196 nm 約 +17、零點約 207 nm) |

- `lo`、`hi`:180 到 350 nm 的最小與最大值,給縱軸用;`bad`:HT 超過 `HT_BAD`(600 V)的最長波長(樟腦磺酸 187.5 nm、兩個蛋白質 186.5 nm)。
- 光路上除了儀器以外吸掉的光 `sampleA()` = `ABS[樣品]` + `waterA(λ, 光徑 cm)`(示意):樟腦磺酸在 285 nm 約 0.083(文獻 ε 34.5 × 2.406 mM),蛋白質在 190 nm 約 0.9;水在 1 cm、185 nm 是 2,往短波長變大。
- `htAt()` = min(1000, 280 × 10^((sampleA + sysA) / 6)) V(示意;增益 ∝ 電壓的 Z 次方,這裡 Z 取 6,所以 HT 與吸光度不是線性,log HT 約與 A 成正比)。大部分波長約 310 到 320 V,總吸光度約 2 時到 600 V。
- `noiseCD()` = 0.03 × 10^(0.7 × 總吸光度) mdeg(示意),只加在掃描曲線上;HT 高的區段雜訊很大。
- 讀值:ΔA = θ ÷ 32982;左旋光、右旋光 = 10^−(A ± ΔA/2)(A 是 `sampleA`,示意;兩者的差由 ΔA 算出)。

### 旋光(`OR`)

`alpha = spec × 1 dm × c`:(+)-α-蒎烯 51.14 × 0.8591 = +43.93°、(−)-α-蒎烯 −51.28 × 0.8590 = −44.05°(頁面顯示 −44.0°)、蔗糖 66.37 × 0.1 = +6.64°、空白 0。穿過檢偏鏡的光 `malus(φ, α)` = sin²(φ − α),φ 的 0 定為空白最暗的位置,所以最暗處就在 φ = α。

掃描曲線每 0.5° 一點,加 0.25% 的雜訊;`fitAlpha()` 對 y = a + b cos2φ + c sin2φ 做最小平方,α = ½ atan2(−c, −b),取 −90° 到 90°(讀數每 180° 重複)。掃描要涵蓋 120° 以上才算(`foundAlpha()`)。用 Node 試 199 個種子,最大誤差 0.03°;影片的種子 3 與 9 得 +43.92° 與 −44.03°。

## 偏振的算法

- 光沿 +z 走;迎著光看(從 +z 往 −z)x 向右、y 向上。順時針 = 右旋;旋光度為正 = 順時針(和 3D 的預設視角一致,讀者正好是迎著光看)。
- 電場 E = Re{J e^{i(kz − ωt)}},`WK` = 2π/2.4(畫出來的波長 2.4 單位)、`WW` = 2π(每秒一個週期),都是示意。`handed()` = Im(Jx\* Jy):正是逆時針(左旋)。
- 單色器出來是水平線偏振 `J_H`。光彈調變器的兩個軸在 ±45°,y 那一邊落後 δ:`jonesPEM(δ)`;δ = `pemDelta(t, k)` = 90° × k × sin(2πt / `TP`),`TP` = 2.4 秒(實際約 20 µs)。δ = +90° 時左旋、−90° 時右旋、0 時是原來的線偏振,中間是橢圓;實機哪半個週期對哪個旋向依元件方向而定,頁面只說「壓一次、拉一次,各給一種旋向」。
- 旋光:樣品管裡振動方向依 z 線性轉到 α(`rotJ()`),出來以後是轉了 α 的線偏振;檢偏鏡 `analyzeJ(J, φ)` 投影到透光軸 (sin φ, cos φ)。
- 圓二色:左右吸收的差只有萬分之幾到千分之幾,3D 不放大這個差(振幅只依 `sampleA` 變暗);差異畫在小圖的「偵測器的光 ×50」與讀值條。

## 座標、尺度與模型

- 1 單位約 1 cm,y 朝上,桌面頂面 y = 0,光軸高度 `BY` = 10。底座 64.4 × 70.4(中心 z = −1)。外殼三塊:後半 `rear`(燈與單色器,`[0, 46, -22]`)、左前樣品室蓋 `lid`(藍灰色上蓋,`[-16, 38, 8]`,繞 x 轉 −0.2)、右前 `right`(電路,`[30, 20, 0]`)。
- 元件位置 `P`(俯視 x, z):燈 `XE` (25, −28.3)、入口狹縫 `S1` (17.5, −28.3)、稜鏡 `PR1` (9.3, −28.3)、中間狹縫 `S2` (3.65, −22.65)、稜鏡 `PR2` (−2, −17)、出口狹縫 `S3` (−2, −13);之後光沿 +z 走在 `SX` = −2:光彈調變器 z = −4、比色管 5、樣品管 0 到 10(1 dm)、檢偏鏡 14(不用時停在 x = −11)、光電倍增管的窗 21.2。兩個稜鏡各偏折 45°;`prism()` 依進出方向擺頂角(最小偏向,底邊在光偏過去的那一側)。
- 色散:狹縫板上的位置 = `G` × (1/λ² − 1/λ選)(µm⁻²,石英折射率約 A + B/λ²),`G1` = 0.9、`G2` = 0.45(示意)。另一個振動方向的光在板上高 `POL2` = 1.1 單位,落在縫口上方被擋掉(第一個稜鏡 45%、第二個 15% 亮度,示意)。
- 光彈調變器的石英棒 5.2 × 1.25 × 1.25,轉 45°;一端黏著壓電元件。棒子隨 `pemDelta` 伸縮 ±4.5%、發光強弱跟著變(放大很多倍)。
- 手性分子放在儀器左邊的桌面上(`MOLX` = −51.5、`MOLZ` = 10),一個四面體的中心原子帶四個不同顏色的球,和它對 x = `MOLX` 的鏡像;兩個一起以相反方向旋轉,所以一直是鏡像。只在第 02 章出現(`W.molK`)。
- 標籤 8 個:`XE`、`MONO`、`PEM`、`SMP`、`ANA`、`PMT`、`LOCK`、`N2`;`SMP`、`PEM`、`PMT` 的小字每格由 `labelText()` 改。`ANA` 在互動模式只有檢偏鏡在光路上才出現。

## 光路

- `buildRays()`:燈 → 反射罩口 8 點 → `S1` → 第一個稜鏡的入射面 9 點 → 出射面 3 點散成 `FANL` 各波長(加上被擋的另一個振動方向)到 `S2` 板 → 第二個稜鏡 → 再散一次到 `S3` → 沿 +z 五段(`W.I` 是每段的光強)。鍵是 `W.lambda` 與 `W.I`,掃描或轉檢偏鏡時才重建。
- 光點:燈到第一個稜鏡(白)、第一個稜鏡到出口狹縫(單色)。樣品區不放光點,改畫偏振的波。
- `BEAMS`:樣品區五段光柱,亮度 `0.6 × W.I[i]`。光電倍增管的窗跟著最後一段變亮。

## 偏振的畫法

- `stageSegs(t)` 每格算出五段(出口到調變器、調變器到樣品、樣品管裡、樣品到檢偏鏡或偵測器、檢偏鏡到偵測器)的瓊斯向量與振幅。`drawWave()` 每 0.1 單位一點(每段最多 170 點)更新三組幾何:電場尖端的線、從光軸拉到尖端的細線(每 3 點一條)、半透明的面。只更新頂點,不重建幾何。
- `drawStation()`:每段前頭一站,畫外圈、偏振的形狀(扁的時候兩端各一個箭頭 = 雙箭頭;圓的時候順著轉向一個箭頭)與一支白色的「這一瞬間的電場」箭頭(線偏振時來回擺、圓偏振時轉圈)。
- 外殼蓋著時不畫(`sstep(.3, .8, W.explode)`)。第 03 章 `W.decomp` 打開時,線偏振的面變淡,另畫左旋(橘)與右旋(藍)兩個分量。
- three.js 只把 `visible === false` 當成隱藏,`drawWave()` 裡的 `vis` 要轉成布林(曾經因為 `null` 而讓上一個模式的波留在畫面上)。

## 譜圖與讀值

- 圓二色:橫軸 180 到 350 nm,縱軸依這一次、上一次與目前樣品的 `lo`/`hi` 加大一點,刻度間距依圖高自動選(`niceStep()`,每格至少約 24 px)。`bad` 以下的區段塗淡灰色、標「HT」;圖例有「HT 過高」。
- 旋光:橫軸 −90° 到 90°,縱軸 0 到 100%(圖高不到 100 px 時每 50% 一格);掃完標出「最暗」的角度。
- 預覽灰點線、這一次青色實線、上一次琥珀色虛線、目前位置用光的顏色畫線與點,滑鼠位置用白色虛線,照 STYLE。最多每秒畫 30 次。
- 讀值卡:圓二色是波長、橢圓度(調變器停住時和旋光一樣寫「未量」,停住的狀態看 `PEM` 標籤的小字)、HT;旋光是檢偏鏡角度、透過的光、旋光度(掃描找到以前寫「未量」)。讀值條:圓二色是左旋光、右旋光(橘、藍);旋光是空白的光(sin²φ)與樣品的光(sin²(φ − α))。大數字:橢圓度(mdeg)或比旋光度(空白寫「不旋光」)。
- 小圖 `drawPol()`(最多每秒 30 次):圓二色時是光彈調變器之後的偏振(虛線橢圓、轉動的箭頭、左旋/右旋/線偏振/橢圓偏振)與偵測器的光(起伏放大 50 倍,過去兩個週期);旋光時是樣品前(灰虛線)、樣品後(實線,α 的弧)、檢偏鏡的透光軸(白虛線)與三行數值;第 03 章另有「線偏振 = 左旋 + 右旋」。

## 修改的切入點

- **文字:** `CAPS`;字卡在 `updateDOM()`;標籤在 `label()` 與 `frameCommon()` 的 `labelText()`;說明 `noteHTML()`;讀值卡與讀值條的標題 `setModeText()`;圖例 `updateDOM()`;小圖 `drawPol()`;牆上 `screenTex()`。中英一起改,跑 `node scripts/check-i18n.mjs --list cd/index.html`。

## 設計取捨

- 主角是偏振。光的波長、頻率與調變都放慢放大很多倍(說明框小字有寫);振動方向用「面 + 尖端線 + 細線」的波與每段一站的雙箭頭或轉圈箭頭表示,小圖另外畫迎著光看的樣子,轉動相機時也不會看錯方向。
- 水平線偏振照 Chirascan 的說法;預設視角從 +z 那一側看,讀者正好迎著光,看到的順時針就是頁面說的右旋與 (+)。
- 實機沒有另一片偏振片(由晶體石英稜鏡產生線偏振),模型照實機;第 03 章字幕講稜鏡把兩個振動方向分開、狹縫只放一個。
- 旋光模式把波長改成 589 nm(鈉 D 線);專用旋光儀的光源寫在說明框小字。
- HT、樣品與水的吸光度、雜訊、峰寬、β 褶板整條都是示意;有文獻值的是 32982、樟腦磺酸的兩個峰(位置與由 Δε 算出的高度)、肌紅蛋白 222 nm、HT 的門檻、各樣品的比旋光度。
- 3D 不放大左右吸收的差(約千分之幾),免得看起來像左右旋光差很多;差異放在讀值與「×50」的小圖。
