# FTIR 紅外光譜儀:維護說明

`ftir/index.html` 是單一 HTML 檔,用 three.js 0.183.2(jsDelivr 的 ES module,經 importmap 載入)繪圖,元件標籤用 three.js 的 `CSS2DRenderer`,不需要建置。畫面是一台拆開的傅立葉轉換紅外光譜儀(FTIR):光源、準直鏡、邁克森干涉儀(分光鏡、固定鏡、活動鏡)、當尺用的雷射、鑽石 ATR(衰減全反射)與 DTGS 偵測器。可以選樣品、拖曳活動鏡改光程差、換解析度與平均次數、掃描,干涉圖與光譜之間的傅立葉轉換是頁面上真的算的。「導覽」與影片共用同一條 96 秒、8 章的腳本(`?film`、`?rec`)。科學資料與來源見 `../INSTRUMENTS.md`,檢查步驟見 `../docs/VALIDATION.md`。

**正本:** 儲存庫裡的 `ftir/index.html` 就是正本(2026-11-16 新增),直接改這個檔。版面與骨架從 `uv-vis/index.html` 複製後改寫(導覽、影片、手機版面、畫面大小、英文版的做法都相同,見 `../uv-vis/MAINTENANCE.md`);module 的大區以 `// ================= 名稱 =================`、小區以 `// ---------- 名稱 ----------` 標示。

**對應的儀器:** 研究室有一台 Agilent Cary 630 FTIR(鑽石 ATR)。頁面不寫型號;元件的種類以常見的桌上型 FTIR 為例,規格與來源見 INSTRUMENTS.md 的 FTIR 一節。

## 光譜模型

### 取樣與傅立葉轉換

- 干涉圖每經過一個雷射條紋取一點:`LASER_NM` = 632.8 nm(氦氖雷射的波長,常見設計;研究室的 Cary 630 用固態雷射二極體,波長沒有公開),光程差的取樣間隔 `DX` = 0.6328 µm,所以最高到 1 / (2 × `DX`) ≈ 7901 cm⁻¹(取樣定理)。`NFFT` = 16384 點,光譜的點距 `DNU` = 1 / (`NFFT` × `DX`) ≈ 0.964 cm⁻¹;畫 650 到 4000 cm⁻¹(`NU0`、`NU1`,共 `NK` ≈ 3476 點)。
- `FFT` 是就地的基 2 快速傅立葉轉換(正向 e^(−2πi jk/N)),位元反轉表與正弦、餘弦表在載入時建好。實數而且左右對稱的陣列轉換後還是實數,頁面只取實部。
- 真正的光譜 → 干涉圖:每個樣品的單光束光譜 `SB[k]`(0 到 `HALF`)對稱放進長度 `NFFT` 的陣列做一次 FFT,得到干涉圖 `IFG[k]`(光程差 0 到 `HALF` × `DX`,對稱);全部除以空氣的中心峰 `IFG.air[0]`,所以空氣的中心峰是 1。載入時四個樣品各算一次。
- 量一次(`measureOne(key, R, n, seed)`):取 |光程差| ≤ `opdMax(R)` = 1/R cm 的那一段(R 是解析度,cm⁻¹),每一點加上雜訊 `ifgNoise()`(掃一次的標準差 `NOISE` = 2.4 × 10⁻⁴,平均 n 次除以 √n),乘上 Happ–Genzel 切趾(0.54 + 0.46 cos(π j / J)),其餘補 0,做 FFT 取回 `K0` 到 `K1` 那一段。`measure()` 對同樣的條件另外量一次空氣(背景,種子加 0.37),吸光度 = −log₁₀(樣品 ÷ 背景),並算雜訊(見下面);結果放在 `MCACHE`(超過 30 筆整個清掉)。`n` = 0 是沒有雜訊的預覽。
- 解析度與鏡子:4 cm⁻¹ 要光程差 ±2.5 mm(鏡子走 1.25 mm,雷射 3951 條條紋),2 cm⁻¹ 要 ±5 mm。點數 2J + 1:16 cm⁻¹ 1977、8 cm⁻¹ 3951、4 cm⁻¹ 7903、2 cm⁻¹ 15803,都小於 `NFFT`。

### 光、空氣與樣品(示意)

- `throughput(ν)`:光源取 1300 K 的黑體輻射(`planckNu`,c₂ = 1.4388 cm·K;`PK` 是 2549 cm⁻¹ 的峰值),乘上低波數的截止(520 到 760 cm⁻¹ 由 0 升到 1)、高波數慢慢變弱(5200 到 7300 cm⁻¹),再乘鑽石本身在 2600 到 1900 cm⁻¹ 的吸收(兩個高斯,最低處約剩三成)。數值都是示意,只決定單光束的形狀與各處雜訊的大小。
- `ATM`:二氧化碳 2361、2338、2349、667、650、684 cm⁻¹ 幾條,水氣在 3480 到 3960 cm⁻¹ 放 70 條、1340 到 1920 cm⁻¹ 放 90 條細線(位置與強度由 `hash()` 決定,是示意,不是真的譜線表)。背景與樣品都乘同一層空氣,所以相除以後抵消。
- `SAMPLES`:`bands` 是 ATR 量到的吸光度帶 `[波數, 峰高, 半高寬]`,線形是一半高斯、一半勞倫茲(`absAt()`)。四個樣品:香草醛(van)、濾紙(cel,幾乎是純纖維素)、針葉樹木粉(wood)、空氣(air,沒有吸收帶)。峰的位置來源見 INSTRUMENTS.md;木粉的相對峰高照 Traoré 等 2018 在 Cary 630 鑽石 ATR 量的松木(由圖目視估,1025 cm⁻¹ = 1),心材抽出物(樹脂酸)的 1690 cm⁻¹ 不放;香草醛與濾紙的峰高、三個樣品的寬度都是示意。`color` 是 3D 上樣品的顏色。

### 雜訊與讀值

- 雜訊:和同條件、沒有雜訊的那一條相減,取 1900 到 2700 cm⁻¹ 的均方根(含鑽石自己吸收、光比較少的那一段),顯示在 `#vN`。2026-11-16 用頁面量到:4 cm⁻¹ 掃 1 次約 0.006、16 次約 0.0016、64 次約 0.0007;16 次時 16 cm⁻¹ 約 0.0007、2 cm⁻¹ 約 0.0022。
- 偵測器的訊號:`W.out` = (中心峰 + 這個光程差的干涉圖) ÷ 2(直流的一半加上干涉的一半),空氣在光程差 0 時是 1;顯示在 `#vD` 並決定輸出那一段光的亮度。
- 雷射條紋:|光程差| ÷ `LASER_NM`;雷射偵測器的亮度 `W.lz` = 0.5 + 0.5 cos(2π |光程差| / λ)。

## 座標、尺度與模型

- 單位與方向同 UV-Vis:一個單位約 1 cm,y 朝上,桌面頂面 y = 0,紅外光的光軸高度 `BY` = 10;雷射在上方 `LY` = 12.6,和紅外光平行走同一個干涉儀。
- 元件位置 `P`(俯視 x, z):光源 `SRC` (−24, −24)、準直鏡 `CM` (−24, −12)、光圈 `AP` (−13, −12)、分光鏡 `BS` (0, −12)、固定鏡 `FM` (0, −27)、活動鏡 `MM` (15, −12)、雷射 `LS` (−7, −12)、小鏡子 `LP` (0, −5)、雷射偵測器 `LD` (6.5, −5)、ATR 的入口鏡 `MA` (0, 2)、鑽石 `DIA` (0, 6)、出口鏡 `MB` (0, 10)、偵測器 `DET` (0, 22)。準直鏡與分光鏡的朝向用 `bis()` 由位置算出;`MA`、`MB` 在 x = 0 的直立平面上轉(`tiltMirror()`,法線是兩個方向的角平分線)。
- 活動鏡:`O.MM.base` 放在 `mmPos(x)` = 原位置 + `MMK` × x / 2(x 是光程差,cm);`MMK` = 20,所以畫面上的移動放大了 20 倍(2 cm⁻¹ 的 ±2.5 mm 鏡子行程畫成 ±5 個單位)。滑軌、磁鐵與底座不動,鏡子、背板與線圈跟著動。
- ATR:台面頂面 `ATR_TOP` = `BY` + 4,中央留洞,鑽石是倒過來的方錐台(頂面 2.3、高 1.4,和台面一樣高);紅外光從 `MA` 斜向上 45° 打到鑽石頂面中心 `DIA_TOP` (0, 14, 6),全反射後斜向下到 `MB`,再水平到偵測器。實際的取樣面直徑約 1 mm(Cary 630 的鑽石 ATR,真正有作用的區域約 200 µm),這裡放大很多。漸逝波 `O.EVA` 是頂面上方一片很薄的發光圓片(厚度放大);樣品 `pile` 是一小堆(香草醛、木粉),`sheet` 是一片(濾紙)。壓桿 `O.PRESS` 依 `W.press` 上下(1 是壓下)。
- 外殼:`rear` 展開時移到 `[0, 44, −24]`、`front` 到 `[0, 34, 30]`;淡出與青色外框同 UV-Vis。ATR 台面不在外殼裡(真的機器樣品台也在外面)。

## 光路

- `buildRays(W)`:所有光線畫在一個 `LineSegments` 裡(最多 4000 個頂點),片段著色器做出沿光路前進的亮點(同 UV-Vis)。紅外光用 `BEAMOFF` 五條:光源 → 準直鏡 → 分光鏡;分光鏡 → 固定鏡、分光鏡 → 活動鏡(來回畫成同一條);合在一起之後 → `MA` → 鑽石頂面 → `MB` → 偵測器,亮度乘 `W.out`,有樣品時鑽石之後再乘 0.85。雷射:雷射 → 分光鏡 → 兩面鏡子 → 合在一起 → `LP` → `LD`,合在一起之後的亮度乘 `W.lz`。`raysKey` 是光程差(到 10⁻⁶ cm)、`W.out`、`W.lz` 與樣品,改光路時會影響光線的欄位都要加進去。
- 光點 `buildPhotons()`:光源到分光鏡、分光鏡到兩面鏡子、分光鏡經 ATR 到偵測器四段,最後一段的亮度乘 `W.out`。
- 光柱 `BM`:準直鏡到分光鏡、兩支手臂、合在一起的那一段各一根半透明的圓柱;活動鏡那一根每格依鏡子的位置重新擺(`placeBeam()`)。

## 干涉圖與光譜圖

- 即時播放最多每秒畫 30 次(`plotDrawnAt`),`?rec` 每格都畫;畫布像素乘 `currentCSSZoom`(沒有就 `uiScale()`),提示框的座標除回來。
- `drawIfg()`:橫軸光程差。平常是 ±1/R(mm),縱軸用 asinh 壓縮(`S0` = 0.004),中心峰還在、兩旁很小的起伏也看得到,圖上寫「縱軸壓縮,小起伏放大」;按「放大中間」(`S.zoom`,導覽第 04 章是 `W.ifgZoom`)時橫軸縮到 ±22 µm、縱軸改成線性,取樣點之間用三次內插(`ifgSmooth()`)。一欄跨好幾個取樣點時畫那一欄的最大與最小。掃描中,掃過的部分(到目前的光程差)是加了雜訊的橘色,沒掃到的是灰色;藍線是目前的光程差。
- `drawSpectrum()`:橫軸照紅外光譜的習慣,左邊是高波數(4000 到 650 cm⁻¹);「吸光度」畫樣品 ÷ 背景,「單光束」畫背景(灰)與樣品(青)各自的光(除以背景的最大值)。沒有掃描也沒有上一次時畫預覽(灰點線)。上一次的結果是琥珀色虛線。一個畫素取那一段的最大與最小,細的水氣線才不會被跳過。傅立葉轉換的那 0.5 秒,一道亮光由左往右掃過;掃描中圖的中間寫「記錄干涉圖 k / n」或「傅立葉轉換中」。

## 設計取捨

- 頁面真的做傅立葉轉換:光譜 → 干涉圖 → 截斷、加雜訊、切趾 → 光譜。所以解析度變差時峰變寬、平均次數變多時雜訊變小,都是算出來的,不是另外套的效果。
- 干涉圖的縱軸平常用 asinh 壓縮:照比例畫的話,中心峰旁邊只剩一條平線;壓縮以後看得到遠處還有起伏(細的譜線與尖的吸收帶的資訊在那裡)。
- 活動鏡的移動放大 20 倍、鑽石放大很多、漸逝波的厚度放大很多,都是為了看得見。
- 空氣的水氣線是示意的位置;真的水氣線很多很細,這裡只要看得出「背景有、相除以後抵消」。
- 在手機上元件標籤只留名稱,小字(活動鏡移動、條紋數)看左上的讀值卡。
