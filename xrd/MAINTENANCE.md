# XRD X 射線繞射儀:維護說明

`xrd/index.html` 是單一 HTML 檔,用 three.js 0.183.2(jsDelivr 的 ES module,經 importmap 載入)繪圖,元件標籤用 three.js 的 `CSS2DRenderer`,不需要建置。畫面是一台拆開的粉末 X 射線繞射儀:輻射防護櫃、直立的測角儀(刻度盤)、左臂的 X 射線管與發散狹縫、索勒狹縫,中間的粉末樣品,右臂的索勒狹縫、鎳濾片、接收狹縫與閃爍計數器。可以選樣品、拖曳 X 射線管或偵測器改繞射角 2θ、拿掉鎳濾片、換晶粒大小、掃描出整張繞射圖;「導覽」與影片共用同一條 96 秒、8 章的腳本(`?film`、`?rec`)。科學資料與來源見 `../INSTRUMENTS.md`,檢查步驟見 `../docs/VALIDATION.md`。

**正本:** 儲存庫裡的 `xrd/index.html` 就是正本(2026-11-16 新增),直接改這個檔。版面與骨架從 `uv-vis/index.html` 複製後改寫(導覽、影片、手機版面、畫面大小、英文版的做法都相同,見 `../uv-vis/MAINTENANCE.md`);module 的大區以 `// ================= 名稱 =================`、小區以 `// ---------- 名稱 ----------` 標示。

**對應的儀器:** 不對應特定型號。以常見的 Bragg-Brentano 粉末繞射儀為例:θ–θ 測角儀(樣品水平不動、X 射線管與偵測器各轉 θ)、銅靶、線焦點、閃爍計數器加鎳濾片。頁面不寫型號;規格的例子(MiniFlex、D8 ADVANCE、NIST 的儀器)與來源見 INSTRUMENTS.md 的 XRD 一節。

## 繞射模型

### 波長、濾片與峰的位置

- 銅的三條特性 X 射線(NIST X 射線躍遷能量資料庫):`LA1` = 1.5405929 Å(Kα1)、`LA2` = 1.5444274 Å(Kα2)、`LB` = 1.392234 Å(Kβ)。每一組晶面在三條線各有一個峰,位置都由布拉格定律 `ttOf(d, λ)` = 2 asin(λ ÷ 2d) 算(n = 1)。Kα2 的強度是 Kα1 的一半;Kα1 與 Kα2 在高角度分得開(80° 時差 0.24°)。
- `lineW(filter)` 是三條線的相對強度,以「有濾片時的 Kα1」為 1:有濾片 [1, 0.5, 0.0039];沒有濾片 [2.381, 1.190, 0.571]。依據:沒有濾片時 Kβ 約是 Kα 的 16%(`KB0`,Bruker),20 µm 鎳濾片讓 Kα 剩 42%(`NI_TA`)、Kβ 剩 0.69%(`NI_TB`,由 NIST 的質量衰減係數算)。所以拿掉濾片時峰變高 2.38 倍,每個強峰左邊多一個約 24% 高的 Kβ 峰(食鹽 (200) 的 Kβ 在 28.58°)。背景也一起乘 2.38(示意)。
- 晶格:食鹽 a = 5.6402 Å(NBS 1953)、矽 a = 5.431144 Å(NIST SRM 640f 證書值),`cubic()` 用 d = a ÷ √(h² + k² + l²);纖維素 Iβ 直接用查證筆記裡的 d 值(由 COD 4114994 的結構算,法式記法,(200) 在 3.867 Å)。

### 峰的寬度與峰形

- `fwhmAt(D, 2θ)` = √(`INSTR`² + 謝樂寬度²):`INSTR` = 0.06°(示意的儀器峰寬;實驗室儀器上矽粉約 0.053 到 0.058°);謝樂寬度 `scherrer(D, 2θ)` = K λ ÷ (D cosθ),K = 0.9、λ = 0.15406 nm,換成度。
- 晶粒大小兩個選項 `sizes`:食鹽與矽 [400 nm, 10 nm](400 nm 取自矽標準品約 0.4 µm 的晶域;10 nm 是示意);纖維素 [5.3 nm, 3.2 nm](5.3 nm 對應 (200) 半高寬 1.53°,和 Nam 等人模擬棉花用的 1.54° 相同;3.2 nm 是挪威雲杉木材纖維素的晶粒厚度,半高寬 2.53°)。
- 峰形 `pv()` 是擬 Voigt(高斯與勞倫茲混合,`eta` 是勞倫茲的比例):食鹽、矽 0.4(示意),纖維素 0(純高斯,和查證筆記的計算一致)。
- 晶粒變小時峰變寬,面積不變:食鹽、矽的 `I` 是峰高(`height: true`),先換成面積再除以新的寬度;纖維素的 `I` 是積分強度,高度 = I ÷ 寬度。

### 強度、背景與非晶

- `crystRaw()` 把每一組晶面、三條線加起來;`sm.k` 讓「有濾片、晶粒大」時最高的結晶峰剛好是 `top` 個計數(食鹽 6000、矽 8000、纖維素 1500;都是示意)。
- 相對強度:食鹽與矽用 1953 年 NBS 標準圖譜量的峰高(食鹽 (111) 13、(200) 100、(220) 55、(311) 2、(222) 15、(400) 6、(331) 1、(420) 11;矽 (111) 100、(220) 60、(311) 35、(400) 8、(331) 13)。纖維素用查證筆記由晶體結構算的積分強度((1-10) 33、(110) 27、(012) 3、(102) 9、(200) 100、34.5° 附近四組 6、4、4、5)。查證筆記另有食鹽不含熱振動因子的計算值,頁面沒有用。
- 背景 `bgAt()` = `bg` × (0.6 + 0.4 e^(−(2θ − 5)/8))(示意:低角度空氣散射多一點)。
- 非晶隆起 `humpAt()`:高斯,最高點 20.5°(`AM_TT`,球磨微晶纖維素,Park 2010),半高寬 9°(`AM_W`,示意,文獻沒找到);Kβ 也有一份在 18.51°(`AM_TTB`)。纖維素的隆起高 250 計數,非晶樣品 740(和微晶纖維素的總散射面積相同);纖維素裡隆起占總面積約 34%(示意,文獻說微晶纖維素的非晶比例依方法是 8 到 40%)。
- `model()` = 結晶峰 + 隆起 + 背景(不含雜訊),預覽、3D 光束的亮度與沒掃描時的讀值都用它。

### 掃描與雜訊

- 每 0.02° 一點(`STEP`),`traceOf()` 在 `model()` 上加泊松雜訊(常態近似,標準差 √N,種子由 `hash` 決定,同一個掃描每次相同)。整條曲線一次算好放在 `traceCache`,畫圖時只畫到目前的角度 `to`。
- 互動的掃描:先用 0.6 秒把臂轉到起點,再用 `SCAN_S` = 6 秒從範圍的下限掃到上限(食鹽與矽 5 到 80°,纖維素與非晶 5 到 50°);種子是 `S.seed × 7.7`(第一次 15.4)。

### 結晶度指數與對到的晶面

- `segalOf()`:主峰高度 = 21 到 24.5° 之間最大的計數;18° 的高度 = 17.9 到 18.1° 的平均;CrI = (主峰 − 18°) ÷ 主峰,沒有扣背景。只對纖維素、而且掃描過 24.5° 才有數字。沒有雜訊時晶粒 5.3 nm 是 81.8%、3.2 nm 是 66.4%(Park 2010 的 Avicel 沒扣背景是 81.0%)。
- `matchAt()`:找現在角度貢獻最大的那一組晶面(Kα 與 Kβ 分開算);要高過背景加隆起,而且在自己峰頂一半以上,才算「對到」。顯示在讀值區與說明。

## 座標、尺度與模型

- 單位與方向同 UV-Vis:一個單位約 1 cm,y 朝上,桌面頂面 y = 0。測角儀的中心(樣品表面)在 `C0` = (0, 29, 0),掃描平面是 z = 0;刻度盤在後面(z 約 −6.2,半徑 22.5),刻度只畫上半圈。
- 兩支臂都繞 `C0` 轉 θ = 2θ ÷ 2。臂的座標:x 沿臂往外、y 和臂垂直(遠離樣品表面那一側)、z 朝前。偵測器臂 `armD` 直接 `rotation.z = θ`;X 射線管臂是 `armTP`(`scale.x = −1`,鏡像)裡的 `armT`,同樣 `rotation.z = θ`,所以兩支臂共用同一套座標。世界座標由 `updateArms()` 每格算進 `P`(焦點 `P.F`、燈絲 `P.FIL`、接收狹縫 `P.G`、偵測器的窗 `P.DW`、入射側索勒狹縫的入口 `P.SS`)。
- 元件在臂上的 x:焦點與接收狹縫都在 `R` = 20(測角儀半徑,示意;實際桌上型約 15 cm、落地型約 30 cm);發散狹縫 `X_DS` = 16;兩個索勒狹縫 `X_SS` = 12.5;鎳濾片 `X_NI` = 16.6;偵測器 21.4 到 29.4。
- X 射線管:管軸和光束垂直(線焦點要和掃描平面垂直);銅靶在下端、燈絲在上方 1.7,下半截是透明的玻璃(看得到燈絲、電子、銅靶),上半截是金屬外殼,頂端接高壓電纜,底下兩條冷卻水管;鈹窗在面向樣品的那一側。
- 樣品座 `HOLD`:不隨臂轉,只依 `W.spin` 自轉(互動時每秒 0.6 弧度,示意);粉末的顏色由 `SAMPLES[...].color` 決定。
- 外殼:`rear` 移到 `[0, 14, −46]`、`roof` `[0, 44, −6]`、`sideL` `[−48, 6, 0]`、`sideR` `[48, 6, 0]`、`doors` `[0, 10, 50]`;淡出與外框線同 UV-Vis。門是淡琥珀色的鉛玻璃(`MAT.lead`,不透明度 0.16)。

## 光路

- `buildRays()`:焦點是一條沿 z 的線(`LZ` = ±0.6,示意),每個 z 各畫 3 條入射光到樣品上照到的範圍 `footprint()`(從焦點往下 θ ± 0.5° 的兩條光打到樣品表面的位置,最多到 ±2.5;`DIV` = 1° 是示意),再由照到的每一點畫到接收狹縫(會聚到同一點),最後進偵測器。繞射光的亮度 `W.kD` = 0.1 + 1.5 √(扣掉背景的計數 ÷ 峰頂),在鎳濾片之前另外乘 `niFactor()`(有濾片時前段亮 2.38 倍)。`W.stray` > 0 時(第 03 章)另畫四條往前後歪的琥珀色光,停在入射側索勒狹縫的入口。`raysKey` 是 2θ、`W.kD`、`W.stray` 與 `W.niOut`。
- `buildPhotons()`:電子(燈絲 → 銅靶,亮度 `W.elec`)、入射光、繞射光三組光點。
- `updateBeams()`:入射與繞射的半透明扇形(`wedges`,只有前後兩片三角形)、樣品上照到的範圍 `FOOT`、偵測器窗 `DWIN` 的亮度。
- 繞射錐:每個樣品的主要晶面各一個圓錐(`coneGeo()`:頂點在樣品、軸是入射光方向、半頂角 2θ、長度 `R`),用裁切平面 `CLIP` 只畫樣品表面以上;邊緣的圓 `rl` 在 `R` 的距離,所以偵測器的接收狹縫剛好在圓上時就是那一組晶面的峰。`updateCones()` 每格把整組錐轉到入射光的方向;亮度 = max(`W.cones` × (0.18 + 0.82 × 接近程度), `W.flash` × 接近程度 × 0.9),接近程度以 max(1.2°, 1.5 × 峰寬)為寬度。互動時 `W.flash` = 1(偵測器靠近峰時那一個錐閃一下),導覽第 05 章用 `W.cones`。
- 晶格放大(`BLOW`):食鹽 (100) 面的一小塊,鈉(紫)與氯(綠)交錯,4 層、每層 9 個,畫面上的層距 `BSP` = 2、波長 `LAMV` = 1.0926(λ ÷ d 和食鹽 (200) 相同,所以畫面上的角度就是真的布拉格角)。`buildBragg(θ, t, op, path)` 畫晶面、d 的標示、兩道光(上層與下層)的入射與反射波(正弦曲線,從同一個波前出發,隨 t 前進)、θ 的弧、下層多走的兩段(琥珀色,各 d sinθ)與兩條波前(虛線)。小字 `DL`:`d`、`th`(θ)、`path`(多走 2d sinθ)、`st`(兩道光同步或錯開;路程差除以波長離整數 0.12 以內算同步,0.38 以上算錯開)。

## 標籤

- `label(key, { arm, comp, anchor, title, sub, below, ax })`:`comp` 是引線在元件上的端點、`anchor` 是標籤的錨點,有 `arm` 時是那支臂的座標(跟著轉);`below` 讓標籤掛在錨點下方;`ax` 是錨點在標籤的哪裡(0 左、0.5 中、1 右),X 射線管與鎳濾片的標籤往右長、索勒狹縫往左長,1024×768 時才不會碰到左上的說明或彼此。`placeLabels()` 每格更新位置與引線。
- `declutter()`(`render()` 最後呼叫):量 `AVOID` 裡看得到的面板(分頁列、標題、讀值卡、說明、控制面板、說明框、繞射圖、字幕、結束導覽、手機的停靠區與把手),依 `LBL_ORDER`(晶格小字最先,再來 X 射線管、樣品、偵測器、發散狹縫、索勒狹縫、鎳濾片、測角儀)一個個放;碰到面板、超出畫面或碰到已經放好的標籤就藏起來(連同引線)。互動時每 3 格量一次,藏起來的要離開 10 px 才再出現;導覽、影片與 `?rec` 每格量、不用遲滯,同一個 t 結果相同。

## 繞射圖與讀值

- `drawPlot()`:橫軸 2θ(樣品的範圍)、縱軸計數(上限 `niceUp()` 取整);即時播放最多每秒畫 30 次,`?rec` 每格都畫;畫布像素乘 `currentCSSZoom`(沒有就 `uiScale()`)。每一欄畫那一段的最大與最小(`columns()`),窄峰不會被跳過。順序:纖維素與非晶的隆起加背景(淡紫色塗滿)、預覽(灰色點線,只在沒有掃描也沒有上一次時)、上一次(琥珀色虛線)、這一次(青色)、目前角度的直線與點、晶面名稱(米勒指數;沒有濾片時加 Kβ;纖維素與非晶標「非晶」;依畫出來的高度由高到低放,疊到已經放好的就不寫)、Segal 用的兩個高度(琥珀色虛線與點,標 18°)。
- 讀值卡:2θ、d = λ ÷ (2 sinθ)(nm,四位小數)、計數(掃描過的地方用掃描的數據,其他用 `model()`)。偵測器條以「峰頂 + 隆起 + 背景」為滿格。

## 設計取捨

- 用 θ–θ 測角儀:樣品水平不動,學生不會以為樣品要轉;說明框寫樣品只在原地自轉(減少晶粒朝向不均)。
- X 射線管照真的方向擺(管軸和光束垂直),下半截畫成透明,看得到燈絲與銅靶。
- 繞射光的亮度跟著模擬的計數:「角度對了才亮」就是頁面上看到的事。開根號是為了背景也看得到一點。
- 繞射錐的軸跟著入射光轉,所以 X 射線管動的時候錐也在動,這是真的幾何;導覽用從上往下的視角,錐的邊才看得出是一圈圈的弧。
- 晶格放大用真的 λ ÷ d,所以抵消(48.37°)與加強(31.70°)的角度和右邊的偵測器一致。
- 標籤寧可藏起來也不蓋到面板:不同視角下位置會變,用 `declutter()` 統一處理,不逐一調位置。
- 結晶度指數故意只用 Segal 的兩個高度、不扣背景,並在說明框寫明只是一種估法(結果和文獻的 Avicel 沒扣背景的 81% 接近)。

## 示意與缺口

- 示意:儀器比例、元件位置、狹縫寬度、光束張開角度(1°)、線焦點長度、計數的大小(`top`、`bg`)、儀器峰寬 0.06°、峰形的勞倫茲比例、背景的形狀、非晶隆起的寬度(9°)與高度、食鹽與矽「小」的晶粒 10 nm、樣品自轉速度、掃描速度(6 秒)。
- 查證筆記的缺口,頁面當示意處理:食鹽沒有熱振動因子的資料(頁面改用 1953 年實測的峰高,不用計算值);纖維素的相對強度是研究代理自己算的(來源是公開的晶體結構,但沒有用 Mercury 核對);非晶隆起的寬度與木粉的完整繞射圖都沒找到(所以非晶樣品用球磨纖維素,不放木粉);鎳濾片厚度用 20 µm 的計算值。
- 手機上元件標籤只留名稱,計數看左上的讀值卡。
