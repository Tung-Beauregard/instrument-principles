## 共用檢查命令

在儲存庫根目錄執行：

```sh
node scripts/check-site.mjs
node --check assets/app.js
node scripts/check-render-quality.mjs
node scripts/check-camera-nav.mjs
node scripts/check-mobile-panels.mjs
node scripts/check-fields.mjs
node scripts/check-plot.mjs
```

- `check-mobile-panels.mjs`（2026-10-22）檢查手機版面板收合：`assets/mobile-panels.js` 的手機尺寸判斷沒有改；`assets/mobile-panels.css` 的大括號成對，而且除了「平常藏起細條」（`.mp-tab{display:none}`）與只在手機上才建立的轉向提示，每條規則都限定在 `html.mp` 或 `html.mp-suspended` 底下（桌機版面不會被改到）；UV-Vis、NMR、質譜儀-不同分析器比較、光譜-光與分子、層析-GC 與 HPLC、GC-MS 都載入這兩個檔、只呼叫一次 `createMobilePanels`、開了轉向提示、導覽中會暫停、細條有名稱與內容說明；前五頁用底部停靠區、控制面板與譜都能收合、按「掃描」或「收訊」這類按鈕會打開譜、收起控制面板時一併關掉說明框；GC-MS 不用停靠區。只檢查原始碼，實際的版面與操作要在瀏覽器看（見下方「手機版面板收合」）。
- `check-plot.mjs`（2026-10-22）檢查數據畫圖 `plot/parsers.js` 與 `plot/figure.js`：在程式裡合成 .spc（float 與整數 Y）、兩種 .asp、PerkinElmer 的 DSC 與 TGA csv（含等溫段與反轉點修剪）、xlsx（自己打包 zip）、LCQ .RAW（run header、索引與峰值）讀回核對數值，再核對質譜平均的視窗加總與加權 m/z、DTG 峰溫，以及四種圖的 SVG 有框線、軸名、標示且沒有 NaN。不需要真實數據檔。
- `check-fields.mjs` 檢查四種分析器共用的電場示意 `assets/analyzer-fields.js`（2026-10-07 以 `check-saddle.mjs`、`saddle-field.js` 的名字新增，2026-10-08 擴充並改名）：離子阱的球在不動或翻太慢時滾出去、翻得夠快時留得住，太輕的（q 超過 0.908）留不住，掃描時由輕到重依序沿軸向射出；四極柱加上直流之後只留中間那一種，太輕的沿交流甩出去的方向、太重的沿直流拉走的方向出去，掃描時三種輪流留住；飛行時間兩輪各三顆都打到偵測器、輕的先到，反射鏡開著時兩顆 m/z 195 的到達時間差小於 0.08 秒、關掉後大三倍以上，524 與 195 的時間比接近 √(524/195)；Orbitrap 的擺盪頻率比等於 √(m/z) 的反比；同一個時間點重算的結果相同；GC-MS 與質譜儀-不同分析器比較都有載入這個檔。
- `check-camera-nav.mjs` 檢查共用視角操作 `assets/camera-nav.js` 的滾輪判斷（滑鼠滾輪、觸控板滑動、捏合、同一串事件沿用第一下），以及八個教材頁面（離子阱質譜的兩個畫面各算一頁；2026-10-07 起含 `mass-analyzers/`，2026-10-08 起含 `spectroscopy/`、`chromatography/`）都載入這個檔、建立視角操作並每格呼叫 `nav.step(dt)`。
- `check-site.mjs` 檢查教材清單與入口靜態備援是否一致（2026-10-20 起也檢查分享預覽：每頁的 `og:url` 是自己的正式網址、`og:image` 指向 `assets/og/` 裡存在的圖、寬高 1200 × 630，`og:title` 與 `og:description` 都有）（2026-10-08 起含分類：每個有教材的分類在備援裡有一區、順序和清單相同、分類名稱一致，每份教材出現在它所屬的每一區）、本機資源與相對連結是否存在、每份教材是否有「← 儀器入口」，以及頁面裡沒有控制字元（2026-10-08 起；`node --check` 會接受 NUL，但瀏覽器解析 HTML 時把它換成 U+FFFD，整個 module 就載入失敗）。
- 教材頁的 JavaScript 內嵌在 `index.html` 的 `<script type="module">` 裡，`check-site.mjs` 不檢查語法。修改後可把該段內容另存成暫存的 `.mjs` 檔，用 `node --check` 檢查後刪除暫存檔。

### 視角操作（2026-10-07）

六份教材共用 `assets/camera-nav.js`（參考 The Plane of Focus；質譜儀-不同分析器比較 2026-10-07 加入）。逐頁檢查：

| 操作 | 預期結果 |
| --- | --- |
| 滑鼠拖曳、右鍵或 Shift 拖曳、滾輪 | 旋轉、平移、縮放（縮放有上下限）。 |
| 觸控板雙指滑動、兩指捏合 | 平移、縮放。 |
| 觸控螢幕單指、雙指 | 旋轉；雙指平移與捏合縮放。 |
| 按住方向鍵或 W A S D | 左右平移、沿著看的方向前後移動；按住 Shift 加快。 |
| 按住 + − | 縮放。 |
| Q E、R | NMR、UV-Vis、質譜儀-不同分析器比較、離子阱質譜的動畫講解：Q E 轉向，R 回到預設視角（動畫講解的故事模式回到動畫的鏡頭）。GC-MS 的 Q 是質譜面板、R 是原有的重設視角；拆開探索的 E 是組裝與展開，R 回到預設視角。 |

### 重要數值案例

- q = V / (5.1175 × m/z)：500 V 時 m/z 195.09 的 q = 0.501，留得住的最小 m/z = 500 / (5.1175 × 0.908) ≈ 108。
- 射出電壓 0.83 × 5.1175 × m/z：195.09 約 829 V、524.26 約 2227 V、1222 約 5190 V。動畫裡離子要被推到端帽外才算排出，掃描排出一章實測全部出阱時的電壓略高（836、2240、5236 V）；加成離子與負離子兩章的掃描比較慢，611 在約 2593 V（計算值 2596）就全部出去了。
- 8500 V 對應的最大 m/z：q = 0.83 時約 2001，q = 0.908 時約 1829。
- 端帽交流頻率：β(0.83) ≈ 0.736，0.736 × 760 / 2 ≈ 280 kHz。
- MS/MS：把 611.16 放到 q = 0.25 需要 0.25 × 5.1175 × 611.16 ≈ 782 V，這時留得住的最小 m/z 約 168，碎片 303 與 465 都留得住。
- 關掉端帽交流電壓：算出的 m/z 偏大 0.908 / 0.83 ≈ 1.094 倍，195.09 會落在約 213。
- 加成離子（Fiehn 表的離子質量）：蘆丁 M = 610.15338，[M+H]⁺ 611.1607、[M+Na]⁺ 633.1426、[M+K]⁺ 649.1165、[2M+H]⁺ 1221.3140、[2M+Na]⁺ 1243.2960；[M−H]⁻ 609.1461、[M+HCOO]⁻ 655.1516、[2M−H]⁻ 1219.2995。緩激肽 M = 1059.5614，[M+2H]²⁺ = (1059.5614 + 2 × 1.007276) / 2 = 530.7880。
- 同位素：蘆丁 [M+H]⁺（C₂₇H₃₁O₁₆）的 M+1 約 0.30、M+2 約 0.08；緩激肽 [M+2H]²⁺（C₅₀H₇₅N₁₅O₁₁）的 M+1 約 0.61、M+2 約 0.21，峰的間距 1.0034 / 2 ≈ 0.50。主控台 `lcq.isotopePattern('C27H31O16')` 可以重算。
- 峰寬：一般掃描事件雜訊的標準差 0.19，半高寬 2.355 × 0.19 ≈ 0.45；放大掃描 0.13，約 0.31。
- 空間電荷（示意）：8 倍裝填時 sc = 7，m/z 偏 0.0004 × 7 × m/z（195 多 0.55、524 多 1.47、1222 多 3.42），半高寬 0.45 × (1 + 0.5 × 7) ≈ 2.0。
- MS/MS 活化：β(0.25) ≈ 0.179，0.179 × 760 / 2 ≈ 68 kHz。

### 重要數值案例

- 光柵方程（示意的 1200 條、夾角 20°）：sinθ = 1200 × λ(nm) × 10⁻⁶ ÷ (2 cos 10°)。θ(190) = 6.647°、θ(320) = 11.242°、θ(550) = 19.578°、θ(1100) = 42.081°；畫面上兩片光柵轉 θ(λ) − θ(550)：−12.931°、−8.336°、0、+22.503°。1100 nm 時 sinθ = 0.670，程式的 0.98 上限用不到。依 `P` 的擺放，兩片光柵的入射與出射夾角是 20.07° 與 20.05°。
- 換燈：λ < 320 nm 是氘燈；319.99 nm 氘燈、320 nm 鹵素燈。影片約 20.0 秒換成氘燈、約 24.2 秒換回。
- 吸光度（`absorbAt()`，0.2 / 1 / 4 nm）：DPPH 517 nm 0.920 / 0.920 / 0.919；福林酚 765 nm 0.677 / 0.677 / 0.677（曲線最高點在 780 nm，0.688）；葉綠素 663 nm 0.840 / 0.839 / 0.829；氧化鈥 451.3 nm 0.860 / 0.849 / 0.720（4 nm 比 0.2 nm 低 16%）。
- 透射率 T = 10^(−A)：0.920 → 12%、0.849 → 14%、0.720 → 19%、0.677 → 21%。
- 縱軸上限 `ymax`（0.2 nm 曲線的最大值乘 1.1，往上取到 0.2 的倍數）：DPPH 1.2、福林酚 0.8、葉綠素 1.4、氧化鈥 1.0。
- 氧化鈥的 14 帶和 NIST SRM 2034 證書表 1 的 1 nm 一欄四捨五入到 0.1 nm 相同（241.12、249.89、278.13、287.22、333.48、345.38、361.25、385.61、416.25、467.82、485.23、536.56、640.50 nm），只有第 10 帶的 451.3 對應 2 nm 一欄的 451.32（1 nm 一欄是 451.45）。
- 雜訊 σ（`noiseSigma()`，吸光度的標準差）：500 nm、A = 0 時 0.2 / 1 / 2 / 4 nm 為 0.0027 / 0.00054 / 0.00027 / 0.00014；氧化鈥 451.3 nm 0.2 nm 0.0088、4 nm 0.00037；DPPH 517 nm 1 nm 0.0015。程式註解寫「2 nm、500 nm 附近約 0.0001 A」，實際是 0.00027。
- 雜訊的統計：DPPH 1 nm、種子 11 的整條曲線 1201 點，雜訊除以 σ 的平均 0.012、標準差 0.957。
- 掃描：每個樣品約 6 秒（範圍 ÷ 6 nm/s），曲線點數 1201、1201、801、681（DPPH、福林酚、葉綠素、氧化鈥）。第一次掃描的種子是 2 × 7.7 = 15.4，第二次 23.1。
- 影片：`FILM_DUR` = 92 秒；三段掃描每秒 52.2 nm（DPPH 1 nm，800 → 330）、42.5 nm（氧化鈥 4 nm，500 → 330）、38.6 nm（氧化鈥 0.2 nm）；第 06 章燈光閃爍的範圍 0.80 到 1.20 倍。
- 鹵素燈用 3000 K 黑體：普朗克曲線的最大值在 966 nm（`PMAX = planck(966)`，維恩定律 2.898 × 10⁻³ m·K ÷ 3000 K）。
- 簡化的影響（不是頁面上的數字，供改公式時比較）：把狹縫內的透射光平均後再取對數，氧化鈥 451.3 nm 在 4 nm 時是 0.686，程式直接捲積吸光度得 0.720；2 nm 時 0.814 對 0.818；DPPH、葉綠素、福林酚的差別小於 0.002。
