2026-10-02 建立；2026-10-05 補上四份教材的效能回歸步驟；2026-10-06 新增 NMR 教材的操作步驟與數值案例，2026-10-07 隨 NMR 改版更新。其他教材的完整科學數值案例仍待補，見 [HANDOFF.md](./HANDOFF.md)。

## 共用檢查命令

在儲存庫根目錄執行：

```sh
node scripts/check-site.mjs
node --check assets/app.js
node scripts/check-render-quality.mjs
```

- `check-site.mjs` 檢查教材清單與入口靜態備援是否一致、本機資源與相對連結是否存在、每份教材是否有「← 儀器入口」。
- 教材頁的 JavaScript 內嵌在 `index.html` 的 `<script type="module">` 裡，`check-site.mjs` 不檢查語法。修改後可把該段內容另存成暫存的 `.mjs` 檔，用 `node --check` 檢查後刪除暫存檔。

## 網站走查

### 畫質與效能回歸（2026-10-05）

- `check-render-quality.mjs` 檢查各教材(2026-10-06 起含 `nmr/`)的 module 語法、穩定 60 FPS 不降級、持續慢幀與極慢幀降級一次、手動完整不被覆寫、長時間背景間隔不觸發降級、各解析度像素預算，以及 60/120/144/240 Hz 輸入的 60 FPS 節流。
- 四份教材各切換「自動／流暢／完整」，確認模型、粒子和標籤仍出現；再跨教材與重整確認選項保留。`?perf=1` 僅供本地顯示診斷，不能把不同場景 FPS 當作前後對照實驗。
- 在 390×844、768×1024、1280×800 檢查控制區與畫質選單可用；GC-MS 窄版由「設定」開啟，LCQ 的選單在導覽列下方。用 Tab 與選單方向鍵確認焦點可操作。
- LCQ：進入「自己操作」，確認粒子與操作台出現；退出回到播放。切換完整/流暢後畫布正常。
- GC-MS：讓自動進樣完成，確認 TIC、時間與質譜隨播放推進；切換拆開/組裝；窄版設定能開關，畫質選單不溢出。
- UV-Vis：切到氧化鈥、0.2 nm 並掃描，確認波長與吸光度更新、曲線出現；開始/結束導覽能回到操作。`?film&rec&t=64` 應呈現「07 · 掃描」固定畫格。
- LCQ 離子之旅：外觀/組裝/展開、Full MS/MS-MS、播放/停止導覽、鍵盤移動控制框與重設版面仍可用。確認穩定圖背景和離子標記都可見。

本次實際完成：上述畫質、主要操作、三種尺寸、本機四份教材與入口/主站連結走查、UV-Vis 固定 REC 畫格；未見 JavaScript error。軟體繪圖環境有 Three.js shader 浮點精度 warning。完整 LCQ/離子之旅 MP4 匯出、全長導覽逐格檢查、GPU 硬體模式的量化前後比較未執行；匯出採程式路徑核對，尚不能視為完整錄影驗收。

1. 用靜態 HTTP 伺服器預覽，例如 `python -m http.server 8000`，開 `http://localhost:8000/`。
2. 依 AGENTS.md 第 6 節走一遍：主頁 → 入口 → 清單中每份教材 → 入口 → 主頁。
3. 每頁在 390 px、768 px 與桌面寬度各看一次：沒有橫向捲動、文字沒有被切掉、按鈕不重疊。
4. 用 Tab 鍵確認焦點看得見；瀏覽器 console 沒有錯誤。

## lcq-3d：LCQ 離子之旅

程式結構見 [lcq-3d/MAINTENANCE.md](../lcq-3d/MAINTENANCE.md)，數值來源見 [INSTRUMENTS.md](../INSTRUMENTS.md)。

### 外部依賴

- three.js 0.183.2：jsDelivr，經 importmap 載入。
- Google Fonts：DM Mono、Noto Sans TC、Outfit。
- 錄影時才載入 jsDelivr 上的 mp4-muxer 5.2.2。
- 需要 WebGL2；錄影需要 WebCodecs 的 `VideoEncoder`（Chrome、Edge）。沒有時「錄成影片」按鈕不顯示。

### 操作步驟與預期結果

| 步驟 | 預期結果 |
| --- | --- |
| 開啟頁面 | 出現實驗桌與儀器，離子流已在跑。左上分頁列的「離子之旅」是目前頁；「階段」讀值在注入、冷卻、掃描之間循環。 |
| 機身切換外觀、組裝、展開 | 外觀：機殼蓋住儀器。組裝：看得到三個真空區的玻璃與壓力標籤。展開：零件沿導軌拉開、玻璃淡出、零件標籤出現。 |
| 點任一零件 | 左側說明換成該零件的介紹，鏡頭移近該零件。 |
| Full MS 自動循環 | 掃描時質譜依序長出 195.1、524.3，以及 Ultramark 1022 至 1922 的一排峰；穩定圖上的點往右移，到 q = 0.83 後消失。 |
| 切到 MS/MS | 注入後，m/z 195 以外的離子被趕出；活化後出現 m/z 138；掃描時先出 138、再出 195。 |
| 拖「RF 振幅」滑桿 | 「自動循環」關閉。往右推，射出點 m/z 跟著增加，離子依序射出；拉回最左邊，入口透鏡轉為綠色並重新注入。 |
| 拖動資訊框 | 標題說明、控制面板、穩定圖、質譜都能從框面或上緣把手拖動；按鈕與滑桿照常操作，不會觸發拖動。 |
| 縮放資訊框 | 拖右下角可在 0.5 至 2.2 倍之間縮放；重新整理後位置與大小保留；「重設版面」全部還原。 |
| 播放導覽（或按 C） | 約 2 分 21 秒、12 段字幕。控制面板縮成一列按鈕，穩定圖與質譜在右側，字幕在下方中央，三者不重疊；字幕與示波窗也能拖動。再按一次或按 Esc 停止，回到原本的模式與機身狀態。 |
| 錄成影片（Chrome、Edge） | 出現進度條；完成後可儲存 1920×1080、30 fps、約 141 秒的 MP4。 |

### 重要數值案例

- 注入時射出點 `CY.M` = 50：q(195.1) = 0.83 × 50 / 195.1 ≈ 0.213；q(524.3) ≈ 0.079，左側讀值「m/z 524 的 q<sub>z</sub>」應顯示 0.079。
- 掃描時，某種離子在射出點等於自己的 m/z 時到達 q = 0.83 並被射出，例如射出點經過 524.3 時 MRFA 的峰出現。
- MS/MS 活化：`M_ACT` = 0.25 / 0.83 × 195.1 ≈ 58.8，此時 q(195.1) = 0.25；穩定邊界 0.908 對應 m/z ≈ 53.7，也就是前驅離子的 27%。
- 穩定圖：a = 0 時穩定區右端在 q ≈ 0.908。

### 目前無法覆蓋

- 沒有自動化的瀏覽器測試；WebGL、CDN 與錄影只能人工確認。
- 只在 Chromium 系瀏覽器確認過；Safari、Firefox 與真實觸控裝置未測試。
- 科學數值的來源頁碼尚未逐項記錄（見 INSTRUMENTS.md）。

## nmr：NMR 核磁共振

程式結構見 [nmr/MAINTENANCE.md](../nmr/MAINTENANCE.md)，數值來源見 [INSTRUMENTS.md](../INSTRUMENTS.md)。2026-10-07 起版型改成和 UV-Vis 相同，以下步驟以這一版為準。

### 外部依賴

- three.js 0.183.2：jsDelivr，經 importmap 載入。
- Google Fonts：IBM Plex Mono、Noto Sans TC（和 UV-Vis 相同）。
- 需要 WebGL2。頁面沒有錄影按鈕；影片在作者電腦上用無頭瀏覽器逐格錄製（見 MAINTENANCE.md「錄影」）。

### 操作步驟與預期結果

| 步驟 | 預期結果 |
| --- | --- |
| 開啟頁面 | 磁鐵剖開，看得到磁力線、主要零件標籤與放大鏡；讀值卡為「90°、0.6 Hz、—」；下方螢幕是香草醛的預覽虛線與結構式，圖例寫「預覽；按「收訊」收一張譜」。分頁列的「NMR」是目前頁。 |
| 拖曳脈衝角到 30° | 讀值卡變 30°；放大鏡裡 B₁ 與磁化向量出現，M 倒下 30°；縱向 87%、橫向 50%；預覽虛線變矮。放開後 B₁ 熄滅。 |
| 拖到 180° | 說明寫「幾乎沒有橫向分量，線圈收不到訊號」；預覽變成一條平線。 |
| 回到 90°，按「收訊」（NS 16） | 發射路徑沿電纜亮琥珀色、線圈發光，接著接收路徑亮薄荷綠，螢幕畫出 FID，圖例顯示「收訊中 · 第 n / 16 次」；前兩次慢動作，之後加快；約 8 秒後做傅立葉轉換，讀值 S/N 182。 |
| 累加改 64 再收 | 約 9 秒收完，S/N 364；上一張（NS 16）以琥珀色虛線留著，圖例列出兩張的 NS 與線寬。 |
| 勻場改 4 Hz 再收 | 勻場管短暫發光；FID 衰減得比較快，譜峰變寬變矮，NS 16 時 S/N 27。 |
| 點譜三次 | 香草醛依序放大到 7.52 至 6.98 ppm（標出 H-2 d、H-6 dd、H-5 d）、7.452 至 7.402 ppm（H-6 的 1.8 Hz 分裂、右上「1 Hz = 2.0 ppb」），第三下回到整張；放大過程中要放大的峰一直在畫面裡。 |
| 換乙酸乙酯 | 譜清空、回到整張；結構式畫在左邊；點譜放大到 OCH₂ 四重峰（4.24 至 4.00 ppm），再點一次平移到 CH₃ 三重峰（1.37 至 1.15 ppm）。 |
| 外殼「組裝」與「剖開」 | 組裝：弧形外殼轉回來關上，地上有 5 高斯線，標籤換成外觀用的幾個。剖開：外殼像門一樣打開後淡出。 |
| 視角操作 | 拖曳旋轉；右鍵或 Shift + 拖曳平移；滑鼠滾輪縮放；觸控板雙指滑動平移、捏合縮放；觸控螢幕雙指平移與縮放。按住方向鍵或 W A S D 移動、Q E 轉向、+ − 縮放，Shift 加快；R 平滑回到開頁的視角。焦點在脈衝角滑桿時方向鍵只改滑桿；導覽中這些按鍵與滾輪不作用。 |
| ? 說明 | 開啟操作說明與數值來源，再按一次關閉。 |
| 導覽 | 100 秒、15 段字幕；寬螢幕時譜圖螢幕在右上角、「結束導覽」在上方中間。按 Esc 或「結束導覽」回到原本的樣品、外殼、譜與鏡頭。 |
| `?film&rec&t=秒數` | 直接畫出影片的某一格，可用來核對字幕、鏡頭、標籤與螢幕。 |
| 390 px、768 px 寬 | 沒有橫向捲動；控制面板與螢幕在下方；窄的譜省略結構式與次要峰標記。 |

### 重要數值案例

- B₀ = 500.13 ÷ 42.577478 = 11.746 T；²H 頻率 500.13 × 0.15350609 = 76.773 MHz；¹³C 為 125.758 MHz。
- 25 °C 族群差 tanh(hν/2kT) = 4.03×10⁻⁵。
- AQ = TD ÷ (2 × SWH) = 65536 ÷ 20661.156 = 3.172 s；SW = 10330.578 ÷ 500.13 = 20.656 ppm；1 Hz = 2.0 ppb。
- 訊雜比（以最高的 3H 單峰計）：90°、線寬 0.6 Hz 時 NS 1、16、64 分別為 45.5、182、364（√NS）；30°、NS 1 為 22.7；NS 16 時線寬 1.5、4、5、10 Hz 分別為 72.8、27.3、21.8、10.9；180° 為 0。
- `spinSystem()`：兩個自旋相差 20 Hz、J = 10 Hz 時，譜線在 −6.18、3.82、16.18、26.18 Hz（相對第一個自旋），內外線強度比 2.618，與 AB 系統的解析解相同；香草醛三個芳香氫的譜線強度總和為 3.000。
- 乙酸乙酯的乙基（五個自旋，Δν = 1430 Hz、J = 7.1 Hz）：OCH₂ 四重峰間隔 7.1 Hz、強度約 1:3:3:1，CH₃ 三重峰約 1:2:1，強度總和分別為 2.000 與 3.000；二階效應造成的細分裂小於 0.1 Hz，0.6 Hz 線寬下看不出來。

### 目前無法覆蓋

- 儲存庫裡沒有自動化的瀏覽器測試；WebGL、CDN 與影片需人工確認（作者電腦上用無頭 Edge 與 Chrome 做過，見 HANDOFF.md）。
- 只在 Chromium 系瀏覽器確認過；Safari、Firefox 與真實觸控裝置未測試。
