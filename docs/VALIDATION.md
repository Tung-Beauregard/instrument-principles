## 共用檢查命令

在儲存庫根目錄執行：

```sh
node scripts/check-site.mjs
node --check assets/app.js
node scripts/check-render-quality.mjs
node scripts/check-camera-nav.mjs
node scripts/check-fields.mjs
```

- `check-fields.mjs` 檢查四種分析器共用的電場示意 `assets/analyzer-fields.js`（2026-10-07 以 `check-saddle.mjs`、`saddle-field.js` 的名字新增，2026-10-08 擴充並改名）：離子阱的球在不動或翻太慢時滾出去、翻得夠快時留得住，太輕的（q 超過 0.908）留不住，掃描時由輕到重依序沿軸向射出；四極柱加上直流之後只留中間那一種，太輕的沿交流甩出去的方向、太重的沿直流拉走的方向出去，掃描時三種輪流留住；飛行時間兩輪各三顆都打到偵測器、輕的先到，反射鏡開著時兩顆 m/z 195 的到達時間差小於 0.08 秒、關掉後大三倍以上，524 與 195 的時間比接近 √(524/195)；Orbitrap 的擺盪頻率比等於 √(m/z) 的反比；同一個時間點重算的結果相同；GC-MS 與質譜儀-不同分析器比較都有載入這個檔。
- `check-camera-nav.mjs` 檢查共用視角操作 `assets/camera-nav.js` 的滾輪判斷（滑鼠滾輪、觸控板滑動、捏合、同一串事件沿用第一下），以及八份教材（2026-10-07 起含 `mass-analyzers/`，2026-10-08 起含 `spectroscopy/`、`chromatography/`）都載入這個檔、建立視角操作並每格呼叫 `nav.step(dt)`。
- `check-site.mjs` 檢查教材清單與入口靜態備援是否一致（2026-10-08 起含分類：每個有教材的分類在備援裡有一區、順序和清單相同、分類名稱一致，每份教材出現在它所屬的每一區）、本機資源與相對連結是否存在、每份教材是否有「← 儀器入口」，以及頁面裡沒有控制字元（2026-10-08 起；`node --check` 會接受 NUL，但瀏覽器解析 HTML 時把它換成 U+FFFD，整個 module 就載入失敗）。
- 教材頁的 JavaScript 內嵌在 `index.html` 的 `<script type="module">` 裡，`check-site.mjs` 不檢查語法。修改後可把該段內容另存成暫存的 `.mjs` 檔，用 `node --check` 檢查後刪除暫存檔。

## lcq-3d：LCQ 離子之旅

程式結構見 [lcq-3d/MAINTENANCE.md](../lcq-3d/MAINTENANCE.md)，數值來源見 [INSTRUMENTS.md](../INSTRUMENTS.md)。

### 外部依賴

- three.js 0.183.2：jsDelivr，經 importmap 載入。
- Google Fonts：DM Mono、Noto Sans TC、Outfit。
- 錄影時才載入 jsDelivr 上的 mp4-muxer 5.2.2。
- 需要 WebGL2；錄影需要 WebCodecs 的 `VideoEncoder`（Chrome、Edge）。沒有時「錄成影片」按鈕不顯示。

### 操作步驟與預期結果

| 步驟 | 預期結果 |
| --- | --- |
| 開啟頁面 | 出現實驗桌與儀器，離子流已在跑。左上分頁列的「離子之旅」是目前頁；「階段」讀值在注入、冷卻、掃描之間循環。 |
| 機身切換外觀、組裝、展開 | 外觀：機殼蓋住儀器。組裝：看得到三個真空區的玻璃與壓力標籤。展開：零件沿導軌拉開、玻璃淡出、零件標籤出現。 |
| 點任一零件 | 左側說明換成該零件的介紹，鏡頭移近該零件。 |
| Full MS 自動循環 | 掃描時質譜依序長出 195.1、524.3，以及 Ultramark 1022 至 1922 的一排峰；穩定圖上的點往右移，到 q = 0.83 後消失。 |
| 切到 MS/MS | 注入後，m/z 195 以外的離子被趕出；活化後出現 m/z 138；掃描時先出 138、再出 195。 |
| 拖「RF 振幅」滑桿 | 「自動循環」關閉。往右推，射出點 m/z 跟著增加，離子依序射出；拉回最左邊，入口閘門轉為綠色並重新注入。 |
| 拖動資訊框 | 標題說明、控制面板、穩定圖、質譜都能從框面或上緣把手拖動；按鈕與滑桿照常操作，不會觸發拖動。 |
| 縮放資訊框 | 拖右下角可在 0.5 至 2.2 倍之間縮放；重新整理後位置與大小保留；「重設版面」全部還原。 |
| 播放導覽（或按 C） | 約 2 分 21 秒、12 段字幕。控制面板縮成一列按鈕，穩定圖與質譜在右側，字幕在下方中央，三者不重疊；字幕與示波窗也能拖動。再按一次或按 Esc 停止，回到原本的模式與機身狀態。 |
| 錄成影片（Chrome、Edge） | 出現進度條；完成後可儲存 1920×1080、30 fps、約 141 秒的 MP4。 |

### 重要數值案例

- 注入時射出點 `CY.M` = 50：q(195.1) = 0.83 × 50 / 195.1 ≈ 0.213；q(524.3) ≈ 0.079，左側讀值「m/z 524 的 q<sub>z</sub>」應顯示 0.079。
- 掃描時，某種離子在射出點等於自己的 m/z 時到達 q = 0.83 並被射出，例如射出點經過 524.3 時 MRFA 的峰出現。
- MS/MS 活化：`M_ACT` = 0.25 / 0.83 × 195.1 ≈ 58.8，此時 q(195.1) = 0.25；穩定邊界 0.908 對應 m/z ≈ 53.7，也就是前驅離子的 27%。
- 穩定圖：a = 0 時穩定區右端在 q ≈ 0.908。

| 視角操作 | 拖曳旋轉；右鍵或 Shift + 拖曳平移；滑鼠滾輪縮放；觸控板雙指滑動平移、捏合縮放；觸控螢幕雙指平移與縮放。按住方向鍵或 W A S D 移動、Q E 轉向、+ − 縮放，Shift 加快；R 平滑回到開頁的視角。焦點在翻倒角度滑桿時方向鍵只改滑桿；導覽中這些按鍵與滾輪不作用。 |

### 重要數值案例

- B₀ = 500.13 ÷ 42.577478 = 11.746 T；²H 頻率 500.13 × 0.15350609 = 76.773 MHz；¹³C 為 125.758 MHz。
- 25 °C 族群差 tanh(hν/2kT) = 4.03×10⁻⁵。
- AQ = TD ÷ (2 × SWH) = 65536 ÷ 20661.156 = 3.172 s；SW = 10330.578 ÷ 500.13 = 20.656 ppm；1 Hz = 2.0 ppb。
- 訊雜比（以最高的 3H 單峰計）：90°、線寬 0.6 Hz 時 NS 1、16、64 分別為 45.5、182、364（√NS）；30°、NS 1 為 22.7；NS 16 時線寬 1.5、4、5、10 Hz 分別為 72.8、27.3、21.8、10.9；180° 為 0。
- `spinSystem()`：兩個自旋相差 20 Hz、J = 10 Hz 時，譜線在 −6.18、3.82、16.18、26.18 Hz（相對第一個自旋），內外線強度比 2.618，與 AB 系統的解析解相同；香草醛三個芳香氫的譜線強度總和為 3.000。
- 乙酸乙酯的乙基（五個自旋，Δν = 1430 Hz、J = 7.1 Hz）：OCH₂ 四重峰間隔 7.1 Hz、強度約 1:3:3:1，CH₃ 三重峰約 1:2:1，強度總和分別為 2.000 與 3.000；二階效應造成的細分裂小於 0.1 Hz，0.6 Hz 線寬下看不出來。

1. 按「導覽」，第 3、4、5 站放大鏡自動打開；按 × 只收起這一站，下一站需要時又會打開。一路按「下一步」到第 5 站（離子源）：桌面寬度放大鏡在可視區左下，不蓋住離子源；768 px 寬時放大鏡在上方；390 px 寬時放大鏡留在左下，整個 3D 畫面往右移，離子源露在放大鏡右邊。下一站畫面移回原位。
2. 第 7 站（偵測器）：鏡頭從正面窗口斜看進去，看得到偵測器、四極桿出口與真空腔；質譜內腔的牆面是均勻的深色，沒有斜條紋或閃爍。第 8 站（完成）飛回全景的途中與全景本身也沒有條紋。
3. 結束導覽，在全景點一下 ALS 自動進樣器、柱溫箱、質譜儀機身：鏡頭各自飛到那台儀器的取景。點「四極桿」這類部件標籤：飛到該部件。從質譜窗口點到內牆：放大整台質譜儀。
4. 先打開放大鏡，再拖曳它：放大鏡跟著移動，視角不轉；放開後留在原處，縮放或轉動鏡頭時仍在可視區裡同一個比例的位置。雙擊放大鏡：回到自動位置。
5. 把鏡頭拉近質譜正面：離正面 18 單位內，正面外殼、窗玻璃與小螢幕逐漸淡出，看得到內部；拉遠恢復。
6. 動畫說明：控制列的「動畫」、說明視窗裡各段的「▶ 看動畫」、質譜面板切到「四極桿」後的「電場動畫」、牆上的四張說明圖（右上角有「點一下看動畫」，轉到沒有被面板擋住的角度點一下）都會打開動畫視窗。上方分頁切換走走停停、保留指數 KI、電子撞擊游離、四極桿四段；可暫停、上一段、下一段、點進度條跳轉，播完按鈕變「重播」。Esc 或 × 關閉，焦點回到打開它的按鈕；從說明視窗打開時，Esc 先關動畫、再按一次才關說明。動畫視窗開著時 3D 不畫、時間軸不走。
7. 動畫的內容：走走停停的藍色（k = 1）先到偵測器、橙色（k = 3）後到，層析圖長出兩支峰；保留指數在每分鐘 3 °C 時 α-Pinene 5.64 分、KI 934，換成每分鐘 10 °C 後 3.98 分、KI 937；電子撞擊游離的第一顆分子變成 M⁺•（m/z 136），再斷成 C₇H₉⁺（93）與中性的 C₃H₇•（43），右下角的質譜照本頁 α-Pinene 的主要離子長出來；四極桿的 77、93、136 在加上直流後只留 93，掃描時依序輪流留住。
