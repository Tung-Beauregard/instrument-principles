# 維護資料更新提示詞

共用規則與文件要求以 [AGENTS.md](../AGENTS.md) 第 0 節與第 8 節為準。本文件只保存任務提示詞，適用於第一次補齊或後續增量更新。

## 更新整個儲存庫的維護資料

讓 AI 取得最新版專案後，貼上以下指令：

```text
請更新 Tung-Beauregard/instrument-principles 儲存庫的維護資料。

先讀最新版 AGENTS.md、README.md 和 docs/HANDOFF.md，
依 AGENTS.md 第 0 節與第 8 節，核對目前程式碼，
補齊或增量更新各儀器的 MAINTENANCE.md、INSTRUMENTS.md、
docs/VALIDATION.md 與 docs/HANDOFF.md，並同步更新 README 的文件索引。

請確認重要函式、狀態、3D 場景、光路或粒子動畫、
科學計算、圖譜、導覽鏡頭、字幕，以及實際存在的錄影功能
都有足以讓其他 AI 接手的維護說明。

以程式確認實際行為，以原廠資料或原始文獻確認科學依據。
缺少來源、無法確認的設計理由或未執行的驗證，請明確標示；
保留公開網站的外觀、功能與網址，遵守公開資料範圍。

請將文件實際寫回專案，執行適用的檢查，
確認差異後提交並推送至目前對應的遠端分支。
保留使用者及其他 AI 的既有變更，不強制推送。

完成後提供文件連結、提交版本、檢查結果與尚待補齊的項目。
```

如果使用一般聊天介面，請一併提供儲存庫內容或相關檔案；無法寫入 GitHub 的工具應交付修改後的檔案，並清楚標明尚未提交或推送。

## 日常修改時的簡短指令

在具體需求前加上：

```text
請先讀 AGENTS.md、README.md、docs/HANDOFF.md，
以及本次涉及儀器的 MAINTENANCE.md，再處理以下需求。
缺少文件時依 AGENTS.md 記錄並補齊本次必要部分；
完成後同步更新受影響的維護文件與交接紀錄，回報實際驗證結果。

本次需求：
〔填入要修改的內容〕
```
