# 英文版（中英切換）

使用者 2026-11-06 要求全站做英文版。做法是同一頁切換：網址、檔案、程式都只有一份，英文寫在中文旁邊。分享預覽（`og:` 標籤與 `assets/og/` 的圖）只給社群網站讀，維持中文。

## 怎麼切換

- 每一頁的 `<head>` 在 `<meta charset>` 後面第一個載入 `assets/i18n.js`（同步載入，不加 `defer`、不是 module），畫面出來之前就決定語言。
- 語言的來源：網址的 `?lang=en` 或 `?lang=zh` 優先，順便記在 localStorage 的 `ip-lang`；網址沒有就用上次的選擇；都沒有是中文。不看瀏覽器的語言設定，所以原本的訪客打開還是中文。
- 英文時 `<html lang="en">`，網址帶 `?lang=en`（複製網址給別人也是英文），站內的頁面連結也帶上（`I18N.link()`）；中文時網址拿掉 `lang`。英文網址要再加參數時寫 `&`，例如 `lcq/?lang=en&t=3:00`。
- 切換鈕由 `i18n.js` 放在分頁列（`nav.sitenav` 或 `nav#sitenav`）的「← 儀器入口」後面，中文頁寫 EN、英文頁寫「中文」；入口放在標題列右邊（`[data-lang-slot]`）。分頁列排不下要橫向捲動時（手機），切換鈕黏在左邊一直看得到。放在分頁列最後的話，3D 教材在 1024×768 這類寬度會被右上的控制面板蓋住；寫成 English 的話，拆開探索的中文分頁列在 1366×768 會壓到控制面板，所以用短的 EN。按下去記住選擇，換成另一個語言的網址重新載入（保留其他參數與 `#`）。語言在載入時就決定，所以程式裡的字串在哪裡算都可以。

## 頁面怎麼寫英文

1. **只含文字的元素**：加 `data-en="English"`。整頁讀完、頁面自己的程式執行之前換掉文字（`readystatechange` 的 `interactive`）。`<title>` 也一樣。元素裡面不能再有元素（有的話用第 2 種）。
2. **有連結、上下標或好幾段的內容**（重點整理、資料來源、說明視窗）：中文放 `lang="zh-Hant"` 的元素，緊接著放一個 `lang="en"` 的元素寫英文。`i18n.js` 注入的樣式只顯示目前語言的那一份。進階教材重點整理上方「先看」那一行是 `<p class="pre" lang="zh-Hant">` 接 `<p class="pre" lang="en">Read first: …</p>`。
3. **屬性**：`data-en-aria-label`、`data-en-title`、`data-en-alt`、`data-en-placeholder`、`data-en-src`、`data-en-href`…，英文時換掉同名的屬性。
4. **程式裡的字串**：`zhEn('中文', 'English')`（全域函式，`i18n.js` 定義）。第一個參數是原本的中文，一個字都不改；第二個參數不能有中文。模板字串也一樣：`` zhEn(`第 ${n} 輪`, `Cycle ${n}`) ``。陣列、物件、數字也可以：`zhEn([[1e8, '億']], [[1e9, 'billion']])`、`zhEn(186, 196)`（英文的字比較長、需要挪位置時）。共用的 module（`assets/*.js`、`plot/*.js`）開頭寫 `const zhEn = globalThis.zhEn ?? ((zh) => zh);`，在 Node 的檢查裡也能載入。
5. 不會顯示的中文（比對檔案內容的字串、程式裡拿來比對的鍵、給維護者看的錯誤訊息）在同一行加註解 `zh-only`。顯示的字串若也拿來比對（例如 `name === '這瓶油'`），兩邊都用同一個 `zhEn`，英文才比得到。

程式讀頁面上的文字（`textContent`）時，讀到的已經是目前語言的文字。程式自己改文字時（按鈕的「播放／暫停」這類）用 `zhEn`，不要讀回靜態的中文。

**中英兩份的 span 會吃到頁面原本的樣式**：頁面若有 `.grp h6 span{…}` 這種以 span 為對象的規則（原本給數值用），新包的 `<span lang="zh-Hant">` 也會被套上，中文的樣式就變了（UV-Vis 的「波長」踩過）。加一條 `… span[lang]{font-family:inherit;color:inherit;letter-spacing:inherit}` 還原，並跑 `check-i18n-zh.mjs` 確認中文的樣式沒變。

## 英文的寫法

- 讀者和中文一樣是高中畢業看得懂：白話，非用不可的名詞第一次出現時解釋。內容、數字、單位、出處都和中文一致，不增減科學內容；只有中文特有的寫法改成英文的慣例（例如命名法則的取代基順序，英文照字母順序），並在該教材的 MAINTENANCE.md 記下來。
- 美式拼法；標題、章名、標籤用句首大寫（sentence case）。
- 不用破折號（—），用逗號、分號、冒號、括號；範圍寫 `94 to 98 °C`。單位和數字之間空一格（`95 °C`、`450 bp`），`%` 不空。原本當「沒有數值」的佔位符 — 照舊。
- 引號與撇號只用半形的 `'` 與 `"`，不用 ’ ‘ “ ”：很多頁的字型第一個是 Noto Sans TC，中文字型裡彎引號是全形，英文會多出一大格空白。中文的「」改成不加引號或半形 `"`。`check-i18n.mjs` 會檢查英文裡的彎引號與破折號。
- 「示意」寫 illustrative 或 example，「實測」寫 measured，「推估」寫 estimated；圖上的示意值照中文一樣標出來。
- 萬、億要換算：1 萬 = 10,000（ten thousand）、1 億 = 100,000,000（a hundred million）；英文的數字用 `toLocaleString('en-US')`。單複數要對（`1 base`、`2 bases`）。
- 型號、文獻與網址照原樣；型號只出現在中文也有的小字裡。不寫提供研究主題的老師姓名（中文、英文都不寫，`check-bio.mjs` 會查）。

### 字幕的長度與速度（2D 教材）

同一句話英文的字母數約是中文字數的兩倍半。播放器在英文時每一句字幕的那一段放慢到每秒最多 17 個字母（`assets/bio-lesson.js` 的 `READ_CPS`），最慢 0.35 倍（`MIN_RATE`），動畫在那一段一起放慢，字幕和畫面照樣對得上；中文一律原速。英文寫精簡，目標是中文字數的 2 到 2.3 倍；中文字幕本來就密的教材（每秒 13 到 16 個字），英文播放時間是中文的 1.5 到 2 倍。另外每一句英文字幕都要在 1366×768 與 1024×768 折成兩行以內（約 170 個字母），三行會把播放列擠出畫面；`check-i18n-layout.mjs` 會逐句檢查。

3D 教材的導覽與影片字幕有自己的時間窗（開始、結束秒數），英文不放慢，照時間窗寫，每秒不超過約 17 個字母；放不下時刪掉最不重要的細節，數字、單位與但書留著。

### 圖上的字（2D 畫布、3D 標籤）

英文比中文寬，很容易超出畫面或疊到別的字。手機上 2D 畫布的字會放大到 1.3 倍（`g.boost`），所以桌機上要留兩三成的空間。寫不下時依序：改短、用常見縮寫、分兩行（`bio-draw.js` 的 `g.text` 與 `g.tag` 遇到 `\n` 會分行畫，2026-11-06 加的）、最後才用 `zhEn` 給英文另一個位置、大小或淡出的時間。中文的畫法不能動。3D 的元件標籤是置中在錨點上的，英文寬了容易跑出畫面或疊到鄰居，名稱與小字都要短；控制面板依內容撐寬，按鈕的英文要短，1024×768 時才不會蓋到標題（UV-Vis 的外殼寫 Closed／Open）。

## 檢查

```sh
node scripts/check-i18n.mjs                 # 每一段給人看的中文都有英文（HTML、JS、content/instruments.json），英文不用彎引號與破折號
node scripts/check-i18n.mjs --report        # 每個檔案還差幾段
node scripts/check-i18n.mjs --list pcr/index.html   # 那個檔案缺英文的每一段（含行號）
node scripts/check-i18n-layout.mjs [資料夾名稱 ...] [--shots 資料夾]   # 2D 教材：逐章逐秒畫一遍中文版與英文版比對
node scripts/check-i18n-film.mjs [資料夾名稱 ...] [--shots 資料夾]     # 有影片模式的五頁 3D 教材
node scripts/check-i18n-zh.mjs [--ref origin/main] [資料夾名稱 ...]    # 中文版和指定版本比，一個字、一個樣式都不該變
```

- `check-i18n-layout.mjs` 自己開靜態伺服器與無頭 Chrome（`CHECK_BROWSER` 可以指定 Edge），桌機（1400×900）與手機直拿（390×844，圖上的字 1.3 倍）各跑一次，每一章每 0.5 秒畫一格，再把「自己調整」的每個選項各畫幾格。中英兩邊的字依畫的順序逐段配對（同一段字分成幾行的，靠 `bio-draw.js` 標的 `ctx.__ml` 併回一段），列出：畫布上還有中文、英文的字超出 960 × 540（中文同一段沒有超出）、英文的字疊在一起（小的那段被蓋住一成以上、而且中文同一對沒有疊；交疊寬度 3 以下不算，多半是字母本身凸出）、頁面上還有中文、選項的字擠出框、放慢到下限還讀不完的字幕、每一句字幕在 1366×768 與 1024×768 會不會把播放列擠出畫面、console 錯誤。它只比對字和字，字壓到圖形要看 `--shots` 的截圖。
- `check-i18n-film.mjs` 開 `?film&rec`，影片從頭到尾每秒一格（`--step` 可改），比對中英兩版看得到的字（用字本身的範圍，不用元素的框），列出英文版還有中文、超出視窗或疊在一起（中文沒有）的字、每秒超過約 17 個字母的字幕（取樣間隔一秒，只列確定太快的）；再開一般模式 1920×1080、1366×768、1024×768 與手機橫拿 844×390，看還有沒有中文、按鈕與標題的字有沒有擠出框（中文沒有）、console 錯誤。GC-MS、離子阱質譜的兩個畫面與數據畫圖沒有影片模式，改用各自 MAINTENANCE.md 寫的方法看。
- `check-i18n-zh.mjs` 從 git 取出指定版本（預設 `origin/main`）放到暫存資料夾，兩邊都用中文打開，比對畫面上每一段文字與它的字型、大小、粗細、顏色、字距（數字遮掉），2D 教材另外逐章每 0.5 秒比對字幕、畫布上的字與「自己調整」的文字。3D 頁自動循環的畫面（例如拆開探索的階段）會因截取的時間不同而有差，看內容判斷。
