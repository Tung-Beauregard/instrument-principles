# 酵素動力學(`enzyme-kinetics/`)維護說明

生化進階分區的一份教材(2026-10-27)。用 2D 動畫一章一章講酵素動力學:E + S ⇌ ES → E + P 的模型與初速度、萜類合成酶的活性怎麼量(GC 小瓶裡反應、戊烷收集產物、GC-MS 加內標定量)、Michaelis–Menten 曲線、kcat 與 kcat/Km、為什麼不用雙倒數圖擬合、三種可逆抑制,以及一個胺基酸突變怎麼改變 kcat。例子以西加雲杉(*Picea sitchensis*)的單萜合成酶 PsTPS-3car2 與 PsTPS-sab 為主(Roach et al. 2014)。播放器、版面與畫圖工具和生化原理分區共用,約定見 `pcr/MAINTENANCE.md` 的「播放器的約定」。讀者假設看過 `terpene-synthase/` 與 `cloning/`,重點整理的第一行連到這兩份。

## 程式的分區(module 由上往下)

1. **數學**:`// BEGIN-MATH` 到 `// END-MATH` 之間只有計算,不畫圖,只用到 `rng`、`lerp`、`clamp`(驗算方法見最後一節)。
   - `KM = 15.8`(μM,PsTPS-3car2 野生型);`mm(s, V, K)`:Michaelis–Menten。
   - `concs(top, n = 9)`:1 μM 到 `top` 的 9 個等比濃度。
   - `rand(seed)`:把種子乘上 2654435761 打散再丟掉前 12 個數的 `rng`(小種子時 xorshift 開頭的數很小,會讓常態亂數偏大);`gauss(R)`:Box–Muller 標準常態;`simulate(S, V, K, sd, seed)`:每點加固定標準差的常態誤差。
   - `fitNL(S, v)`:非線性最小平方。K 固定時最佳的 V 有公式(V = Σv·f ÷ Σf²,f = [S]/(K + [S])),所以只在 log₁₀K ∈ [−2, 4](0.01 到 10⁴ μM)上找:121 個格點找最低,再用黃金分割細找 50 次。最低點落在最上面兩格時 `edge = true`(數據看起來是直線,Km 定不出來)。
   - `fitLB(S, v)`:1/v 對 1/[S] 的一般線性迴歸;v ≤ 0 的點拿掉(`dropped`);截距 ≤ 0 時 K = ∞、斜率 ≤ 0 時 K = 0,兩種都是 `ok = false`。
   - `pct(arr, q)`、`repeatFits(S, V, K, sd, n, seed)`:同樣的設計重做 n 次,回傳兩種方法 Km 的 2.5%、50%、97.5% 百分位與「定不出來」的次數(當成無限大排序)。
   - `progress(S0, V, K, { kd, Kp, tmax, dt })`:時間曲線,d[S]/dt = −V·e^(−kd·t)·[S] / (K(1 + [P]/Kp) + [S]),四階 Runge–Kutta(dt 0.05 分鐘);`pAt(pc, t)`:內插。
   - `INHIB.comp / non / unc`、`appVK(type, V, K, α)`:三種可逆抑制與表觀的 [Vmax, Km]。
   - `perMs(kcat 每分鐘, Km μM)`:kcat/Km 換成 M⁻¹s⁻¹。
2. **資料**:`FAM.car`、`FAM.sab`(野生型與 596 號突變的 kcat、Km、產物比例,見「數值」);`PROD`(產物名稱);`TPS_EFF`、`TPS_KCAT`(第 4 章數線上的四支萜類合成酶);`PC1`、`V01`、`PC2`、`V02`(第 1、2 章的時間曲線與初速度,模組載入時算一次)。
3. **`fit5(S)`**:第 5 章的數據、兩種擬合與 200 次重做,以 `range|noise|seed` 為鍵快取,控制項改了才重算(桌機一次約幾毫秒)。
4. **畫圖小工具**:`rich()`(一行有上下標的字,`_{…}` 下標、`^{…}` 上標,依 `g.boost` 放大,回傳寬度)、`axes()`(刻度字 13 px 的座標軸,y 軸標題放在最寬的刻度字左邊)、`clipped()`、`plotFn()`、`fade()`、`hexa()`(產物)、`zig()`(GPP)、`diamond()`(內標)、`fmtK()`、`vialPath()`(第 2 章的反應瓶)。
5. **`chapters`** 與 **`createLesson`**(控制項、`replay(t0)`)。

## 計算模型與公式

- Michaelis–Menten:v₀ = Vmax[S] / (Km + [S]);Km = (k₋₁ + kcat)/k₁;kcat 遠小於 k₋₁ 時 Km ≈ Kd = k₋₁/k₁。
- kcat = Vmax / [E]ₜ;[E]ₜ = 蛋白質濃度(g/L)÷ 分子量(g/mol)。[S] 遠小於 Km 時 v₀ ≈ (kcat/Km)[E]ₜ[S]。單位換算 kcat/Km(μM⁻¹min⁻¹)× 10⁶ ÷ 60 = M⁻¹s⁻¹。
- 雙倒數:1/v₀ = (Km/Vmax)(1/[S]) + 1/Vmax;誤差傳遞 δ(1/v₀) ≈ δ/v₀²。第 5 章的誤差棒用真正的 v₀ 算(預期的大小),中心放在量到的點上。
- 抑制(α = 1 + [I]/Ki):競爭型 v₀ = Vmax[S] / (αKm + [S]);非競爭型 v₀ = (Vmax/α)[S] / (Km + [S])(假設和 E、ES 結合的解離常數相同);反競爭型 v₀ = Vmax[S] / (Km + α[S])。表觀值:競爭型 Km,app = αKm;非競爭型 Vmax,app = Vmax/α;反競爭型兩者都除以 α。
- 時間曲線與內標換算見「程式的分區」與「示意」。產物量 = 峰面積比 × 內標量 ÷ 校正係數,內標量 2.5 μM × 0.5 mL = 1.25 nmol。

用 node 驗算過(2026-10-27):

- 沒有誤差時兩種擬合都拿回 Km 15.8、Vmax 1(四種範圍)。`fitNL` 和 20 萬格的暴力格點比,540 組模擬數據的殘差平方和最多只多 2 × 10⁻¹⁵(相對),Km 的 log 差在 10⁻³ 內;`fitLB` 和手算的迴歸一致。
- `progress` 沒有失活與產物抑制時,和積分式 Km·ln([S]₀/[S]) + ([S]₀ − [S]) = Vt 用牛頓法解的值差 10⁻⁷ 以內。第 2 章([S]₀ = 5 μM、V = 0.2 μM/min):10 分鐘用掉 9.3%、P ÷ t 是 v₀ 的 96.4%;20 分鐘 17.9%、92.8%;30 分鐘 25.8%、89.4%;60 分鐘 45.9%、79.6%。第 1 章 v₀ = 0.1163 μM/min,P(10) = 1.005、P(60) = 3.493(v₀·60 = 6.98)。
- 三種抑制的速率式等於用表觀參數算的 Michaelis–Menten(α 1 到 6、[S] 0.5 到 200)。α = 3 時:競爭型 Vmax,app 1、Km,app 47.40;非競爭型 0.333、15.80;反競爭型 0.333、5.27。
- 論文表 3 的 kcat/Km 與 kcat ÷ Km 一致(3car2 0.371、L596F 2.521、sab 0.915、F596L 0.157 μM⁻¹min⁻¹;換成 M⁻¹s⁻¹ 是 6.18 × 10³、4.20 × 10⁴、1.53 × 10⁴、2.61 × 10³);倍數 38.57 ÷ 5.86 = 6.58、32.68 ÷ 4.95 = 6.60;Km 比 0.968 與 0.885。換算 0.65 mg/mL ÷ 65 kDa = 10 μM、10 μM ÷ 50 萬 = 20 pM、117.2 ÷ 20 = 5.86、60 ÷ 5.86 = 10.2 秒。
- 200 次重做(種子 1)的 Km 中間 95%:範圍 1 到 60 μM、誤差 2% 時非線性 13.9 到 18.9、雙倒數 5.9 到無限大(35 次算不出);4% 時 12.2 到 22.5 與 3.7 到無限大(49 次);範圍 1 到 8 μM、誤差 4% 時非線性 5.2 到無限大(20 次定不出來)。常態亂數 20 萬個的平均 −0.001、標準差 0.999。
