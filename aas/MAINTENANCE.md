# AAS 原子吸收光譜儀:維護說明

`aas/index.html` 是單一 HTML 檔,用 three.js 0.183.2(jsDelivr 的 ES module,經 importmap 載入)繪圖,元件標籤用 three.js 的 `CSS2DRenderer`,不需要建置。畫面是一台拆開的火焰式原子吸收光譜儀(單光束):燈座轉盤上的四盞空心陰極燈、截光器、氘燈與合光鏡、透鏡、10 cm 長的燃燒器與火焰、噴霧室與霧化器、樣品管與毛細管、示意的單色器(凹面鏡、光柵、凹面鏡)與光電倍增管。可以選溶液(空白、標準 1 到 3、未知樣品)、換元素(換燈)、開關背景校正、按「測量」讀值;左圖是這一次測量的吸光度對時間,右圖是檢量線。「導覽」與影片共用同一條 98 秒、8 章的腳本(`?film`、`?rec`)。科學資料與來源見 `../INSTRUMENTS.md`,檢查步驟見 `../docs/VALIDATION.md`。

**正本:** 儲存庫裡的 `aas/index.html` 就是正本(2026-11-19 新增),直接改這個檔。版面與骨架從 `uv-vis/index.html` 複製後改寫(導覽、影片、手機版面、畫面大小、英文版的做法都相同,見 `../uv-vis/MAINTENANCE.md`);兩張圖的版面、`.foot` 與導覽時分頁列的寫法照 `ftir/`,讀值卡下面的小面板照 `fluorescence/` 的 `.jab`。module 的大區以 `// ================= 名稱 =================`、小區以 `// ---------- 名稱 ----------` 標示。

**對應的儀器:** 不寫型號;元件的種類以常見的火焰式原子吸收光譜儀為例(很多機型是雙光束,這裡畫單光束),規格與來源見 INSTRUMENTS.md 的 AAS 一節。

## 元素、溶液與讀值

- `ELS` 每一項:`lam` 分析線(nm,NIST 的空氣波長取兩位小數)、`cc` 特徵濃度(mg/L,吸收 1% 的光、吸光度 0.0044 的濃度,廠商方法手冊 1996)、`std` 三瓶標準液(mg/L)、`unk` 未知樣品的濃度(推算的示意值)、`unkName`、`bw` 單色器頻寬(nm)、`bg` 未知樣品的背景吸光度(示意)、`rich`(1 表示用燃料多的黃色火焰)、`other` 燈的其他譜線離分析線幾 nm(銅的 +2.65 是 327.40 nm;鋅、鐵、鉻是示意)、`color` 原子在 3D 裡的顏色(示意)。
- 吸光度 = 0.0044 × 濃度 ÷ 特徵濃度(`aAtom()`)。標準 3 都在吸光度 0.2 左右,在手冊列的線性範圍內,所以頁面用直線,不畫彎曲。背景 `aBg()` 只有未知樣品有(來自樣品的基質);背景校正關掉時讀值 = 原子的吸光度 + 背景(`aDisp()`),打開時扣掉。
- 未知樣品:銅 1.89、鉻 3.16 mg/L 是 CCA 保留量 6.4 kg/m³、木材密度假設 500 kg/m³、0.100 g 木粉定容 100 mL 推算的;鋅 0.32 mg/L 是 ACZA 處理材稀釋 10 倍;鐵 2.2 mg/L 是示意水樣。
- 一次測量 `sg = { el, sol, bg, seed, tIn, sp, hold, tOut, done }`。`τ = (t − tIn) × sp`:0.6 秒(`M_MOVE`)溶液到火焰,吸光度以時間常數 0.3 秒(`M_TAU`)爬到平台;2 到 5 秒(`M_R0`、`M_R1`)讀值;5 秒時毛細管回到空白,0.6 秒後訊號掉回 0;圖畫到 7 秒(`M_END`)。`hold` 是導覽 03 到 06 章一直吸標準 3 用的(到 `tOut` 才離開)。這些時間都是示意(來源只寫讀值通常積分 1 到 3 秒)。
- 訊號 `traceVal()` = 吸光度 × `shapeAt()` × (1 + 慢的飄動約 0.4%)+ 快的雜訊(標準差 0.0012),每秒 25 點(`M_HZ`),依 `seed` 決定,同一次測量畫幾次都一樣;讀值 `readingOf()` 就是 2 到 5 秒這 76 點的平均,所以標準液的點會有一點點偏;雜訊很小,R² 顯示 1.0000(約 0.99999;雜訊大小是示意)。
- 檢量線 `fitOf()`:同一個元素量過的空白與標準液(空白算 0 mg/L)做最小平方直線,兩點以上才畫,三點以上才寫 R²;未知樣品的濃度 = (讀值 − 截距) ÷ 斜率(`readout()`),沒有直線時寫 `? mg/L`。

## 座標、尺度與模型

- 單位與方向同 UV-Vis:一個單位約 1 cm,y 朝上,桌面頂面 y = 0;光軸高度 `BY` = 14,沿 +x 走。燃燒器的縫口在 `SLOT` = 12.6,光從縫口上方 1.4 穿過火焰;火焰高 `FH` = 9(示意)、長 10.6(縫長 10 cm)、很薄(一片平面)。
- 元件位置 `P`(俯視 x, z):燈的窗口 `LW` (−33.5, 0)、截光器 `CH` (−30.6, 0)、合光鏡 `BC` (−26.8, 0)、氘燈 `D2` (−26.8, −8.6)、透鏡 `L1` (−18, 0)、火焰中心 `F` (0, 0)、透鏡 `L2` (14, 0)、入口狹縫 `S1` (19, 0)、凹面鏡 `M1` (37.5, −1)、光柵 `G` (27.5, −8)、凹面鏡 `M2` (37.5, −15)、出口狹縫 `S2` (19, −16)、光電倍增管 `PMT` (13.4, −16)。單色器的排法是示意的 Czerny-Turner(來源沒有讀到實際機構)。
- 燈座 `TUR`:轉軸沿 x,在 (−41, `BY` + `RT`, 0),四盞燈(銅、鋅、鐵、鉻,`EKEYS` 的順序)在半徑 `RT` = 4.6 的圓上;第 i 盞在 `TUR.rotation.x = i × π/2` 時轉到最下面、對準光軸。燈是 Ø 3.9、長約 15 的玻璃管(Hamamatsu L233 系列的大小):底座(帶元素符號的環 `bandTex()`)、玻璃、石英窗、開口朝窗口的陰極小杯、環形陽極、雲母片、支架;點亮的那一盞杯裡有紅色輝光 `glow` 與 `halo`(充氖)。
- 截光器 `CHW`:兩片 90° 的葉片,圓心在光軸上方 2.1;轉角由 `frameCommon()` 依時間算,和光線的截光相位同步(葉片擋住光的時候,後面那一段光是暗的)。
- 進樣:噴霧室是沿 z 的半透明圓筒(`CH_Y` = 7.4、半徑 2.4、z 從 −1.6 到 12),前端是霧化器與毛細管接頭,裡面有撞擊球(z = 11)與三片擾流片,底部接廢液管到桌上的廢液瓶;燃燒器頭(鈦)在噴霧室後端的頸上。樣品架在 z = 21,五支管 `TUBEX` 從左到右是空白、標準 1 到 3、未知樣品,前面的小牌子寫 0、1、2、3、?。毛細管 `updateCap(x, lift)` 是一條 CatmullRom 曲線做的管子,只在末端位置或抬起的高度改變時重建。
- 外殼:`lampCov` 蓋燈座、`monoCov` 蓋單色器、`burnTop` 是燃燒室的後牆、頂蓋與排氣煙囪、`door` 是燃燒室前面的玻璃門(組裝時看得到火焰);展開時各自往外飛並淡出,寫法同 UV-Vis。
- 放大格 `INS`:放在火焰右上方 (13, 22, 6),朝向第 04 章的相機位置 `INS_CAM`;背板的字在 `insBack` 的畫布上(載入時依語言畫一次);三組「霧滴」依時間往上走,經過水分蒸發、變成蒸氣、拆成原子,每組三對原子有一對不拆開(示意有些沒拆開,例如氧化物)。
- 牆上的三塊說明螢幕比範本高(中心 y = 104,範本是 64):範本的高度在這頁的導覽裡會被畫面上緣切成只剩下半塊,改高以後每一格不是整塊看得到就是整塊在畫面外。

## 光路

- `buildRays(W)`:所有光線畫在一個 `LineSegments` 裡(最多 7000 個頂點)。片段著色器做出沿光路前進的亮點(同 UV-Vis),另外依 `aK` 截光:1 是空心陰極燈(截光器之後才切,`uChop` 是切的明顯程度,導覽第 06 章 1、其他 0.45),2 是氘燈(錯開半個週期,和燈輪流),0 一直亮(截光器之前、火焰自己的光)。截光每 1/`CHOP_K` ≈ 22 個單位一段、每秒 `CHOP_HZ` = 0.6 次(真的快很多,這裡放慢)。
- 光線:燈的窗口 → 截光器 → 合光鏡 → `L1` → 火焰中央(最細)→ `L2`(交叉)→ 入口狹縫;分析線(淡紫)穿過火焰以後亮度乘透光率 `W.T`;燈裡氖的紅與橘黃兩組淡一點、不被吸收。氘燈(背景校正開時)經合光鏡進同一條路,火焰之後乘背景的透光率 `W.TB`。火焰自己的光(`W.flr`)從火焰往 `L2` 走,一直亮。單色器裡:入口狹縫 → `M1` → 光柵依波長散開 → `M2` → 出口狹縫板;氖的光散得很遠,打到單色器的內壁;燈的其他譜線、氘燈與火焰的連續光落在縫口兩旁,只有縫口那一段(分析線、以及連續光在頻寬內的那一小段)到光電倍增管。`raysKey` 是元素、透光率、背景透光率、氘燈、火焰光、富燃程度與光柵角度。
- `drawStrip()`:出口狹縫板上的亮點與淡淡的連續光帶,縫口挖空;只有 key 變了才重畫。
- `buildPhotons()`:燈的光點(速度和截光的段落一樣,所以光點不會跑到暗的那一段;火焰之後以機率 1 − T 消失)、氘燈的光點、火焰自己的光點,加上燈杯裡被打出來、發光的原子(第 02 章 `W.lampK` 時比較亮)。
- `buildDots()`:不發光、不起光暈的點。火焰裡的原子數 = 150 × (濃度 × 吸入程度 ÷ 標準 3 的濃度),往上飄;在光束附近的原子隨機變成淡紫色一下,表示吸收了光(原子本身不發光,和下一頁 ICP 的「原子自己發光」區分)。霧、大霧滴、毛細管與廢液管裡的液體都是示意的位置與速度。

## 兩張圖、小面板與讀值

- 即時播放最多每秒畫 30 次(`plotDrawnAt`,兩張圖與小面板一起),`?rec` 每格都畫;畫布像素乘 `currentCSSZoom`(沒有就 `uiScale()`),提示框的座標除回來。
- `drawTime()`:橫軸是這一次測量的秒數(0 到 7),淡青色帶是讀值的 3 秒;灰色點線是預覽(選了溶液還沒量,`W.preview`)、青色實線是這一次(畫到目前的 τ,讀完畫一條讀值線並寫數字)、琥珀色虛線是上一次。縱軸上限 `W.yTop`:畫的東西都在 0.12 以下時是 0.15,否則 0.3(互動時平順地換,導覽在 81.6 到 82.4 秒換)。
- `drawCal()`:橫軸濃度(`XM` 是每個元素的上限與刻度),縱軸 0 到 0.3。沒有直線時畫灰色點線(依特徵濃度算的預覽),有就畫青色直線並在左上寫式子與 R²;標準液是青色圓點;正在量標準液時,一個空心圓在那個濃度上往上爬。未知樣品:從吸光度往右碰到直線、再往下讀濃度(青色),上一次的未知樣品是琥珀色虛線(導覽第 08 章就是「沒扣背景」與「扣了背景」兩條)。
- `drawSig()`(左上小面板,示意):偵測器收到的光。被截光器切成一閃一閃的燈光(高度 = 穿過火焰的燈光 I,右邊有標示)、背景校正開時和燈輪流的氘燈、一直亮的火焰的光(底下那一層);電路只量閃的那一段的高度。火焰的光在富燃(黃色)火焰時比較高(示意)。
- 讀值卡與右邊三格:測量中是即時的訊號,讀完停在讀值(`readout()`);`I₀` 是吸空白時的光(歸零後當 100%),`I` = 10^(−吸光度)。濃度卡:標準液寫它的濃度、未知樣品寫對回檢量線的結果、測量中寫「讀值中」。

## 修改的切入點

- **文字:** 字幕 `CAPS`;片頭片尾字卡在 `updateDOM()`;標籤在 `label()` 與 `frameCommon()` 的 `labelText()`;說明 `noteHTML()`;圖例在 `updateDOM()`;圖的軸名在 `drawTime()`、`drawCal()`;小面板的字在 `drawSig()`;放大格的字在 `insBack`;牆上說明 `screenTex()`。中英一起改(`zhEn`、`data-en`),跑 `node scripts/check-i18n.mjs --list aas/index.html`;字幕速度要重算(中文每秒 8 字、英文每秒 17 個字母以內,見 VALIDATION.md)。
- **元素:** 在 `ELS` 加一項、`EKEYS` 加鍵(燈座最多四盞,超過要改 `TUR` 的角度間隔)、`#segEl` 加按鈕、`XM` 加圖的範圍;數字的出處寫進 INSTRUMENTS.md。
- **濃度與背景:** `ELS` 的 `std`、`unk`、`bg`;雜訊與飄動在 `traceVal()`;測量的時間在 `M_*`。改了要重量讀值並更新本文件、INSTRUMENTS.md 與 VALIDATION.md 的數字。
- **元件與光路:** 位置在 `P`;燃燒器、噴霧室、樣品架、燈座的座標是另外寫的常數(`SLOT`、`CH_*`、`TZ`、`TUBEX`、`TUR`);`LW`、`FC` 與光線的路在 `buildRays()`、`buildPhotons()`;移動元件時一起看標籤的兩組座標、`CAMK` 看的點與 `INS` 的位置。
- **導覽:** `FILM_DUR`、`CAMK`、`CAPS`、`LBL_WIN`、`FSEG`,以及 `film()` 裡寫死的秒數(背景校正 81.2 到 84.1、縱軸 81.6 到 82.4、截光 61.8 到 68、火焰光 55.8 到 68、燈 12.6 到 24.4、放大格 36.8 到 42.8、console 68.2 到 93.2、外殼 6.2 到 9.6 與 92.6 到 95.8)。改了 `CAMK` 要確認牆上螢幕沒有被畫面上緣切到(見「修改後要檢查」)。

## 設計取捨

- 單光束:光路比較好懂;說明框小字寫很多機型是雙光束。
- 每一次「測量」畫自己的 0 到 7 秒,而不是一直捲動的長條圖:這樣「這一次、上一次、預覽」三條線可以照其他教材的規則對照。
- 原子不發光、只在吸收時換顏色,和原子發射(ICP)區分;燈杯裡的原子才發光(燈是光源)。
- 截光器放慢到每秒 0.6 次,才看得出一閃一閃;頁面的小面板用同一個相位。
- 背景校正的效果在銅 324.75 nm 很小(示意的背景 0.005),導覽第 08 章縱軸改成 0.15 才看得出兩條線分開;鋅 213.86 nm 的示意背景 0.020,互動時差別比較明顯(0.40 對 0.32 mg/L)。
- 牆上螢幕比範本高:見上面「座標、尺度與模型」。
