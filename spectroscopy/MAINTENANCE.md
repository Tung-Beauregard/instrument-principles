# 光譜-光與分子:維護說明

`spectroscopy/index.html` 是單一 HTML 檔,用 three.js 0.183.2(jsDelivr ES module,經 importmap 載入)繪圖,不需要建置。版型和 `uv-vis/`、`nmr/`、`mass-analyzers/` 相同:左上是標題、讀值卡與簡圖(能量階梯),右上是控制面板,下方是光譜螢幕,場景裡是 CSS2D 零件標籤;「導覽」與錄影共用同一條時間軸(腳本 184 秒,播放時放慢成約 221 秒)。檔案由作者電腦上的原始碼片段串接而成,串接時保留了分區標記,在檔案裡搜尋 `// ==== ` 就能跳到各區。

**讀者設定:** 文字以台灣高中畢業看得懂為準。每一種光只講「讓分子做什麼動作」(原子核翻面、整個分子轉動、化學鍵振動、電子跳上去、打掉內層電子),再講這就是哪一種光譜儀;單位第一次出現時用一句話解釋(例如 cm⁻¹ 是「每公分有幾個波」)。改文案時維持這個程度;譜線來源留在說明視窗的小字與 `INSTRUMENTS.md`。

**正本:** 儲存庫裡的 `spectroscopy/index.html` 是正本,其他電腦或 AI 直接修改這個檔即可。原始碼片段不在儲存庫中;若改用片段重新產生,必須先把儲存庫裡的修改併回片段,避免覆蓋別人的變更。

## 座標、尺度與模型

- 場景單位是顯示單位。地台頂面 y = 0;分子中心在 `MOL_Y` = 104;光源在左(x = −270)、偵測器在右(x = 270),光從左往右走;牆上的電磁波色帶 `RIB` 在 y = 176、z = −296,左邊能量小、右邊能量大。
- 香草醛用平面結構的座標(`ATOMS`,Å),1 Å 畫成 11 單位;醛基朝上、羥基朝下。振動時只移動參與那一根鍵的原子(`IR_BANDS` 與 `RAMAN` 的 `bonds` 是 `BONDS` 的索引)。
- 每一種光都照同一個香草醛。磁鐵只在無線電波出現(`W.magnet`);微波時整個分子繞直立的軸轉(`W.rotAngle`),其他光讓它停在原來的方向;可見光與紫外光、螢光時出現電子雲。
- 這一種光看的地方發亮(`W.look` 是 `LOOK` 的鍵,`W.lookA` 是亮度):原子用自發光、鍵加在振動的發亮上、電子雲調高透明度。互動模式一直微亮(0.32),影片的「比一比」整段亮起。
- 光波、分子振動、電子雲的大小與速度都經過縮放,不是照比例。

## 狀態:S 與 W

- `S` 是互動模式的設定;`W` 是這一格要畫的樣子。影片與導覽由 `film(t)` 直接從時間算出 `W`;互動模式由 `interactive()` 讓 `W` 平滑趨近 `S`。接著 `updateScene()` 套到 3D,`updateDOM()` 更新讀值、簡圖、光譜螢幕與字幕。
- 3D、能量階梯、讀值與光譜螢幕都用同一個 `respond(band, mode, x)` 的結果,改譜線只要改 `00_core.js` 的資料表。
- 光譜螢幕只畫「已經掃過或拖過的範圍」(`S.shown[key]`,影片是 `W.reveal`),所以開頁時是空的;按「掃描」或拖滑桿才畫出來。

## 互動模式

- 選一種光(無線電波、微波、紅外線、可見光、紫外線、X 光),鏡頭用 `nav.flyTo()` 飛到 `VIEW[VIEW_OF[key]]`;「光的其他用法」切換吸收、螢光、拉曼(螢光固定用紫外線)。
- 滑桿調頻率、波數、波長或能量;「掃描」從一端掃到另一端(核磁共振與微波 9 秒、其他 7 秒),光譜螢幕跟著畫出來。微波是 2 到 20 GHz,滑桿對到一群譜線時分子轉快一階。
- 「比較表」打開每一種光看香草醛的哪裡、拿來做什麼的表(導覽時關掉);× 或 Esc 關閉。
- 窄螢幕(980 px 以下)的簡圖預設不顯示,按「簡圖」開關。

## 導覽與影片的時間軸

- 腳本以 `SCRIPT_DUR` = 184 秒寫成;播放、導覽與錄影時整體放慢 `FILM_SLOW` = 1.2 倍,實際長度約 220.8 秒。
- 時間軸(腳本秒數):0.2 到 5.6 開場標題;6 到 19.4「01 光與分子」(開場時光從無線電波一路換到 X 光);20 到 39.4「02 無線電波」(23 到 36 掃描);40 到 53.2「03 微波」(41.4 到 51.8 掃描,分子越轉越快);54 到 74「04 紅外線」;74.8 到 92.4「05 可見光與紫外光」(從 700 nm 掃到 200 nm);93 到 108.4「06 螢光」;108.9 到 125.3「07 拉曼」;125.9 到 135.3「08 X 光」;135.9 到 142.1「09 不是靠光的」(提到質譜與層析);142.8 到 177.8「10 比一比」(146.2 起每 3.4 秒換一種光:核磁共振、微波、紅外、拉曼、紫外、螢光、X 光,這種光看的地方發亮,光譜螢幕放整張譜;170.6 到 177.8 比較表);178.4 起片尾標題。
- 影片版面(`html.film`):讀值卡與能量階梯在左上、光譜螢幕在右上、字幕在下方中央。`freeRect()` 依這三塊實際佔的位置(各自依透明度 `W.skOp`、`W.conOp`、`W.capZone` 加權)算出空出來的長方形;光譜螢幕在右上,所以比較「放在它下面」和「放在它左邊」哪一邊空出來的正方形大,兩種之間平順地換。`applyShift()` 用 `camera.setViewOffset()` 把主角的中心移過去,放不下時用 `camera.zoom` 縮小(最小 0.45 倍);主角的大小是 `VIEW` 的第三個值(`W.focusR`)。字幕用「章名加兩行字」的高度保留位置(`capReserve()`),字幕之間的空檔也不放回來,換句子時畫面不跳。只在影片與寬螢幕(1100 px 以上、寬高比 4:3 以上)的導覽時作用;互動模式與窄螢幕不移。牆上的色帶在開場與最後看整體時清楚,鏡頭靠近分子時調淡。
- 「導覽」按鈕用同一條時間軸即時播放;按 Esc、「結束導覽」或播完,回到原本的光與鏡頭。

## 網址參數

- `?film`:影片版面,自動循環播放;`?t=秒數`(實際秒數)從某一秒開始。
- `?film&rec`:錄影用。`window.__seek(t)` 畫出實際第 t 秒,`window.__dur` 是全長。要看腳本第 s 秒,用 `t = s × 1.2`。
- `?perf=1`:顯示每秒幀數與繪圖裝置(共用的畫質模組)。
- 除錯:主控台的 `window.SPX`。

## 錄影

頁面本身沒有錄影按鈕。影片用作者電腦上的錄影程式(和 NMR 同一支 `record.mjs`,加上 `--page /spectroscopy/index.html`),逐格呼叫 `__seek` 並截圖,編成 1920×1080、30 fps 的 H.264 MP4。錄好的影片不要提交進網站。

## 手機版的面板收合(2026-10-22)

- 共用的 `../assets/mobile-panels.js` 與 `../assets/mobile-panels.css`(用法寫在 js 檔開頭的註解)。`00_core.js` 一開始(`if (REC) root.classList.add('rec');` 之後)建立 `mp`。
- 寬度 760 px 以下或高度 500 px 以下(`MOBILE_QUERY`)時 `<html>` 加上 `mp`,控制面板 `#ctl` 與光譜螢幕 `#console` 搬進底部的停靠區 `.mp-dock`(橫拿時掛在右上角,面板往下展開,下面整條留給 3D),預設各收成一條細條:「調整 · 光的種類、其他用法、<`#tuneName` 括號前的字>、掃描、導覽、比較表、簡圖、說明、畫質」與「<`#conTitle`> · <`#conSample`>」(例如「紅外光譜 · 香草醛」,每 0.4 秒更新)。點細條展開或收起;按「掃描」時 `mp.open('#console')` 打開光譜,兩塊都展開放不下時把光譜捲進畫面。
- 2026-10-24 起,細條改成畫面右緣、垂直置中的「‹」把手(`mobile-panels.js` 的 `rail`,預設開啟):收起的面板整個藏起來,把手直排「調整」「圖譜」,點了面板才從右邊彈出、排在把手左邊(停靠區右緣讓出 CSS 變數 `--mp-rail-w`),把手變成「›」;支援全螢幕的瀏覽器(Android 的 Chrome 等,iPhone 的 Safari 沒有)在把手最下面另有全螢幕鈕。3D 讓位時把手也算進去;手機上說明框的寬度扣掉 `--mp-rail-w`,不蓋到把手。下面幾條寫的「細條」就是這些把手,導覽中一樣藏起來。
- 收起控制面板時一併關掉說明框(`onToggle`)。手機上的說明框放在標題下方(CSS 變數 `--mp-free-top`),太長就在框內捲動;橫拿時蓋在標題上,不擋右側的停靠區。
- 導覽或 `?film` 時(`suspended()`)細條藏起來、面板照導覽原本的方式出現,結束後回到原本的收合狀態;導覽字幕放在停靠區上方(`--mp-dock-h`),橫拿時放在左下。
- 直拿的觸控手機開頁 1.5 秒後提示一次「建議轉成橫式觀看」(`sessionStorage` 的 `mp-rotate-hint`,8 秒後或按 × 收起)。
- 手機版的樣式是 CSS 最後 `html.mp` 開頭的那一段(橫拿時另外把標題排成一行、讀值卡變矮):標題縮小、讀值卡排成一列、導言與頁尾不顯示、控制面板一欄、按鈕內距縮小(六種光一列放得下)、圖例保留。簡圖和 980 px 以下一樣由「簡圖」開關(`html.mp.sk-open`)。桌機與平板不符合 `MOBILE_QUERY`,不加任何 class,版面和以前相同;`scripts/check-mobile-panels.mjs` 檢查共用樣式表的每條規則都限定在 `html.mp` 底下,也檢查本頁的接線。
- `drawPlot()` 改成先更新光譜螢幕的標題、樣品與圖例,再量畫布大小:收起時畫布寬度是 0,以前在 `if (!w) return;` 就離開,細條上的標題會停在開頁時的「光譜」。
- 3D 讓位:`render()` 每一格先呼叫 `mp.applyView(camera)`,手機上(不是導覽或影片)把投影中心平順地移到標題與停靠區之外最大的那塊空地中間(`setViewOffset`),空地小時稍微縮小(`camera.zoom` 最小 0.62),面板展開或收起時跟著移(約 0.3 秒),例如直拿打開「調整」時主角移到面板上方;傳回 false 時(桌機、導覽、影片)才照原本的 `applyShift()`。空地由共用模組每 0.4 秒、面板開關與視窗大小改變時量,不在每一格量。直拿的取景 `fitPortrait()` 仍把鏡頭往後拉,但手機版互動時 `portraitLift()` 是 0(原本固定往上移 0.36,面板收起後主角會擠在上半部、下半部空著),導覽中仍是 0.36。

## 設計取捨(可確認的部分)

- 使用者要求「解釋這些光譜跟分子間的交互作用,做一個最簡單的解釋」,並選了加入螢光與拉曼、形式為 3D 加影片。所以每一種光只講一件事:一份光的能量剛好對上分子的哪一種「階梯」。
- 2026-10-12 使用者回報導覽時字幕擋住分子,並問示範能不能共用同一組原子、比較什麼是用來看什麼的。所以每一段都照同一個香草醛:微波原本用一氧化碳,改成香草醛氣體在真空裡冷到幾 K 的轉動光譜(有人量過,但頁面的譜線是依計算的轉動常數畫的,見 `INSTRUMENTS.md`);螢光原本用通寧水裡的奎寧,改成香草醛的水溶液(放光 330 nm,鹼性時 405 nm,兩者強弱是示意)。可見光仍用 β-胡蘿蔔素當有顏色的對照(香草醛是白色的)。核磁共振的化學位移和 `nmr/` 用同一組數據。
- 每一種光看的地方在分子上發亮,最後加一段「比一比」,互動模式另有「比較表」按鈕。「看哪裡」是教學上的簡化:每一種光都會碰到整個分子,發亮的是那種光最容易看出來的部分。
- 導覽的取景從固定的位移改成「把主角放進面板之間空出來的地方」,畫面大小不同也不會被蓋住;層析頁用同一套。
- 能量階梯的尺每一格差 100 倍,才放得下從 10⁻⁶ eV 到數百 eV 的範圍;各種動作的區塊是大略範圍。
